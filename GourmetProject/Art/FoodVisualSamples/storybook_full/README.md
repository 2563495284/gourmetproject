# 扁平绘本风正式食物重绘

本目录用于整批视觉评审，不直接覆盖游戏当前正式 Sprite。

- 清单来源：`Assets/StreamingAssets/Config/tbdishbase.json`
- 食物数量：61（含隐藏馒头）
- 画风：暖色扁平绘本、水粉笔触、低光泽、彩色手绘轮廓
- 正式文件：`final/<baseId>.png`
- 生成底稿：`sources/<baseId>_chroma.png`
- 每格：512×512 像素
- 透明背景，不含文字、网格、投影和拟人表情

所有图片先在本目录验收，用户确认整批后再决定是否替换正式资源。

## 统一生成提示规范

使用内置图像生成，以选定的抹茶蛋糕 D 版作为画风参考：暖色扁平绘本、水粉笔触、彩色且略有粗细变化的手绘轮廓、低光泽、暖奶油色高光、低饱和有色阴影。每张只表现一个完整食物主体；不拟人、不含文字、网格、投影和品牌标志，不用多个相同食物复制填充格子。

每个食物先在纯色抠图底上独立生成，再移除背景；最终主体保持原始比例，居中放入 `格子包围盒 × 512像素` 的透明画布。非矩形食物的 `.` 格强制保持完全透明。
