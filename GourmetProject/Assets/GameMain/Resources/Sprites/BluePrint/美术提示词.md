```
--ar 1:1 --style raw --no color, flat, cartoon, cel-shading, 3D render

```

## 十、使用建议

| 工具 | 推荐设置 |
|------|---------|
| Midjourney | `--style raw --ar 1:1 --quality 2` |
| Stable Diffusion | ControlNet + Canny edge, 512×512 基础尺寸 |
| DALL-E 3 | 直接使用英文 prompt，勾选 transparent background |

**后处理**：
- 所有生成素材导入 Photoshop → Threshold 调整 → 去色 → 导出 PNG
- 统一色板：`#000000`, `#1a1a1a`, `#333333`, `#4d4d4d`, `#666666`, `#808080`, `#ffffff`
- 帧动画素材需手动对齐切图
