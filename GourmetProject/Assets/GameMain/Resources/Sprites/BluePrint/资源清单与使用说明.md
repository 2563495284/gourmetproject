## 一、通用导入设置

所有精灵在 Unity 中应使用以下统一设置：

| 设置项 | 值 | 说明 |
|--------|-----|------|
| Texture Type | Sprite (2D and UI) | |
| Sprite Mode | **Multiple** (sheet) / **Single** (static) | 见下方逐表说明 |
| Pixels Per Unit | **16** | 匹配设计文档 16px 网格 |
| Filter Mode | **Point (no filter)** | 像素风格，禁用线性过滤 |
| Compression | **None** | 像素画禁用压缩，避免模糊 |
| Mesh Type | Tight | 减少透明像素碰撞 |
| Generate Mip Maps | 取消勾选 | 2D 像素游戏不需要 |

> **快捷操作**：在 Project 窗口选中所有 sprite sheet → Inspector 中批量设置 Pixels Per Unit = 16, Filter Mode = Point。

## 二、精灵表切图规则

### 2.0 切图通用规则

所有 sprite sheet 按 **水平单行排列**。切图方式：

```
Unity Sprite Editor → Slice → Grid By Cell Size
  - Pixel Size: 见各表
  - Pivot: Center (0.5, 0.5)
  - Method: Delete Existing → Slice
```

### 2.1 玩家角色

| 文件 | 尺寸 | 帧数 | 帧尺寸 | 切图 Pixel Size | 帧率 | 说明 |
|------|------|------|--------|-----------------|------|------|
| `player_idle_sheet.png` | 64×32 | 4 | 16×32 | 16×32 | 8 fps | 呼吸循环 |
| `player_run_sheet.png` | 96×32 | 6 | 16×32 | 16×32 | 10 fps | 跑动循环 |
| `player_jump_sheet.png` | 32×32 | 2 | 16×32 | 16×32 | — | 帧0=上升, 帧1=下落 |
| `player_wallslide_sheet.png` | 32×32 | 2 | 16×32 | 16×32 | 4 fps | 轻微晃动 |
| `player_lighter_idle_sheet.png` | 64×32 | 4 | 16×32 | 16×32 | 8 fps | 持打火机呼吸 |
| `player_lighter_run_sheet.png` | 96×32 | 6 | 16×32 | 16×32 | 10 fps | 持打火机跑动 |

**Animator 状态机建议**：

```
Base Layer:
  Idle ──→ Run ──→ Idle
   │        │
   └── Jump (Rising → Falling) ──→ Idle / Run
   └── Wallslide ──→ Idle / Jump

Lighter Layer (override, weight=1 when R key held):
  LighterIdle ──→ LighterRun ──→ LighterIdle
```

**过渡条件**：
- Idle → Run: `|Horizontal| > 0.1`
- Run → Idle: `|Horizontal| < 0.05`
- Any → Jump: `!Grounded` (用 Rising 帧)
- Jump → Idle/Run: `Grounded`
- Any → Wallslide: `onWall && !Grounded`
- Wallslide → Jump/Idle: `!onWall || Grounded`

## 三、各资源详细用法

### 3.1 玩家角色

**静态精灵**（用于 UI 预览、图标等）：
- `player_idle.png` — 默认站立帧
- `player_lighter.png` — 持打火机姿态
- `player_jump.png` — 跳跃姿态
- `player_wallslide.png` — 贴墙姿态

**帧动画**（用于游戏内 Animator）：
- 使用对应 `_sheet.png` 的 Multiple 模式切图后创建 Animation Clip
- 打火机状态和非打火机状态分为两个 Animator Layer
- 打火机 Layer 的权重由 `Input.GetKey(KeyCode.R)` 控制

### 3.2 地形

| 精灵 | 用法 |
|------|------|
| `platform_tile.png` | 在 Tilemap 中作为 Tile 使用。平台宽度 = 此 Tile × N 横向平铺。设计文档：每个平台宽度可变，约 80-160 px |
| `wall_tile.png` | 竖直墙壁 Tile，用于左右边界和灯塔结构。Tilemap 纵向堆叠 |
| `slope_left.png` / `slope_right.png` | 斜坡地形。碰撞用 `PolygonCollider2D` 画三角形（左高右低 / 左低右高）。注意：斜坡物理需独立处理，详见设计文档 6.4 节 |
| `spikes.png` | 地刺陷阱。AABB 碰撞体 (16×10)。打火机光照下叠加红色脉动 shader。黑暗中与地形几乎同色，仅微弱可见 |

**Tilemap 配置建议**：
- 平台层：`Tilemap` + `TilemapCollider2D` + `CompositeCollider2D` (Used By Composite)
- 墙壁层：`Tilemap` + `TilemapCollider2D`
- 斜坡层：使用 `GameObject` 逐个放置 + `PolygonCollider2D`

### 3.3 检查点

| 精灵 | 用法 |
|------|------|
| `checkpoint_inactive.png` | 未激活检查点（灰色）。在 `renderLighting` 中自带挖光圈（半径 55 px），黑暗中可见。显示为灰白圆圈 + 脉动外环 |
| `checkpoint_active.png` | 已激活检查点（绿色）。挖光圈半径 80 px。绿色发光球 + 绿色彩光晕 |
| `checkpoint_pulse_sheet.png` | 激活后持续播放的脉动动画（4帧，6fps）。叠加在 active 精灵上 |
| `checkpoint_endpoint.png` | 终点灯塔基座光柱（金色）。挖光圈半径 130 px |
| `checkpoint_endpoint_pulse_sheet.png` | 终点脉动动画（4帧，6fps） |
| `checkpoint_burst_sheet.png` | 检查点首次激活时播放的一次性爆发动画（5帧，10fps），播放后销毁 |

**检查点逻辑**：
- 首次触碰 → 播放 burst 动画 → 切换到 active 精灵 + pulse 动画 → 设为重生点
- 任意触碰（含回访）→ 能量回满 100% + 播放轻量粒子反馈
- 终点：玩家踩上灯塔基座（40 px 触发半径）→ 胜利

### 3.5 UI

| 精灵 | 用法 |
|------|------|
| `energy_bar_bg.png` | 左下角能量条背景。渲染为 `Image` (Sliced 或 Simple) |
| `energy_bar_fill.png` | 能量条填充。`Image.Type = Filled`, `Fill Method = Horizontal`。fillAmount = currentEnergy / maxEnergy |
| `flame_sheet.png` | 打火机火焰动画。挂在玩家右手位置，R 键按下时播放，松开时停止 |
| `particle_dust.png` | 斜坡滑行尘屑。滑行速度 > 40 px/s 时每 0.04s 生成一个，灰褐色，随机偏移 + 渐隐 |
| `particle_spark.png` | 打火机火花。开灯时随机生成，暖色，向上飘散 |
| `death_overlay.png` | 死亡时全屏叠加。从透明渐变到完全显示（1.0s），配合屏幕震动 + 红色色调 |
| `victory_overlay.png` | 胜利时全屏叠加。中心金色光晕，边缘暗角 |
| `death_particles_sheet.png` | 死亡时角色位置爆发粒子（4帧，10fps），播放一次 |
| `red_dot.png` / `blue_dot.png` | 怪物迷雾预警指示器。在怪物本体不可见时渲染在怪物位置 |
| `invincibility_ring.png` | 复活无敌光环。挂在玩家位置，2s 内旋转 + 呼吸效果。角色本体会 5Hz 闪烁 |

**HUD 布局**：
```
左下角：能量条 (energy_bar_bg + energy_bar_fill)
右下角：进度百分比 (TextMeshPro)
右上角：调试坐标 (开发用) / 全图照亮标记 (开发用)
中央：死亡/胜利蒙版 (条件显示)
```

### 3.6 背景

| 精灵 | 用法 |
|------|------|
| `star_background.png` | 星空背景。Parallax 滚动，玩家高度越高星星越多（通过调整 alpha 或叠加第二层）。放在最远层 |
| `mountain_silhouette.png` | 远山轮廓。Parallax 滚动速度比星空快。Y 坐标随玩家高度偏移。深色不透明，作为天际线 |

**Parallax 层级**（从远到近）：
1. `star_background.png` — 移动速度 × 0.05
2. `mountain_silhouette.png` — 移动速度 × 0.15
3. 游戏地形（Tilemap）— 移动速度 × 1.0

## 四、Animation Clip 创建速查

### 4.1 创建步骤

1. 选中 sprite sheet → Inspector → Sprite Mode → **Multiple** → Apply
2. Sprite Editor → Slice → Grid By Cell Size → 填入对应帧尺寸 → Slice → Apply
3. 在 Hierarchy 选中怪物/玩家 GameObject → Animation 窗口 → Create
4. 保存 `.anim` 文件到 `Assets/GameMain/Animations/`
5. 选中切好的帧精灵 → 拖入 Animation 窗口的时间轴
6. 调整 Samples 到对应帧率

### 4.2 建议帧率

| 动画 | 帧率 | Samples |
|------|------|---------|
| 玩家待机 | 8 | 8 |
| 玩家奔跑 | 10 | 10 |
| 玩家跳跃 | (切换帧，非循环) | — |
| 玩家贴墙 | 4 | 4 |
| 打火机火焰 | 12 | 12 |
| 蚊子 | 12 | 12 |
| 暗影 | 8 | 8 |
| 雾灵 | 4 | 4 |
| 回声蝠 | 10 | 10 |
| 检查点脉冲 | 6 | 6 |
| 检查点爆发 | 10 | 10 |

## 五、代码引用路径

所有资源通过 `Resources.Load<Sprite>()` 加载，路径相对于 `Resources/` 目录：

```csharp
// 玩家
Resources.Load<Sprite>("Sprites/Characters/player_idle");
Resources.Load<Sprite>("Sprites/Characters/player_idle_sheet");

// 怪物
Resources.Load<Sprite>("Sprites/Characters/Monsters/shadow");
Resources.Load<Sprite>("Sprites/Characters/Monsters/shadow_sheet");

// 地形
Resources.Load<Sprite>("Sprites/Items/platform_tile");
Resources.Load<Sprite>("Sprites/Items/spikes");

// 检查点
Resources.Load<Sprite>("Sprites/Items/checkpoint_inactive");
Resources.Load<Sprite>("Sprites/Items/checkpoint_active");

// UI
Resources.Load<Sprite>("Sprites/UI/energy_bar_bg");
Resources.Load<Sprite>("Sprites/UI/flame_sheet");

// 背景
Resources.Load<Sprite>("Sprites/Backgrounds/star_background");
```

对于 sprite sheet，切图后每个帧的路径为 `"Sprites/Characters/player_idle_sheet_0"`, `"_1"`, `"_2"` 等（Unity 自动命名）。
