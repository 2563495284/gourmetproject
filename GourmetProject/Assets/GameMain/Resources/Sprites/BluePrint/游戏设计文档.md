# 光影 — 游戏设计文档

## 一、核心概念

一款**肉鸽like 爬塔游戏**。核心体验分两个阶段：

- **前期**：视野受限 + 怪物威胁 → 「恐惧 + 压力」的攀爬体验
- **后期**：技能成型 + 关卡熟悉 → 「竞速 + 背板」的爽快感

从《掘地求生》(Getting Over It) 获得启发，但将限制维度从**操作**（只有一个锄头）转向**视野**（只有有限光源）。

《掘地求生》的核心张力来自「操作失误 → 进度回退」的物理惩罚。本作的核心张力来自「信息剥夺 → 未知恐惧」的心理惩罚。玩家可能离目标只有几步，但因看不见而在黑暗中绕圈、踩中陷阱、滑下斜坡。

### 肉鸽三要素

| 要素 | 实现 |
|------|------|
| **程序化关卡** | 设计师预制段（level chunk）→ 随机拼接成整张地图 |
| **局内成长** | 到达检查点 → 3 选 1 技能（二段跳、钩索、附着墙等移动技能） |
| **重玩性** | 每局地图不同 + build 不同 + 难度递增 → 无限重玩

## 二、核心循环

```
新一局 → 起点教学段 → [随机段 → 视野焦虑 → 决策 → 到达检查点 → 选技能] × N → 山顶灯塔 → 通关
```

**微观循环**（每段内的紧张-释放节奏）：
```
移动探索 → 视野焦虑 → 决策（省电摸黑 / 开灯看路）→ 到达检查点 → 能量回满 + 选技能（压力释放）
            ↑                          ↓
   怪物威胁 / 地刺 / 斜坡 ←←← 能量消耗
```

**宏观循环**（跨局成长）：
```
开始新一局 → 随机地图 + 随机技能 build → 到达尽可能高的高度 → 获得光之碎片 → 解锁新内容 → 开下一局
```

三层威胁并行：
1. **信息层** — 默认视野只能看到脚下
2. **动态层** — 蚊群 / 暗影 / 斜坡下滑迫使玩家持续操作
3. **静态层** — 地刺陷阱奖励观察、惩罚盲动

## 三、操作方式

| 按键 | 功能 |
|------|------|
| A / D | 左右移动 |
| W / S | （闲置） |
| 空格 | 跳跃（含 0.10s 土狼时间 / 0.12s 输入缓冲） |
| 按住 R | 打火机（按下即点燃，松开即熄灭，消耗能量） |
| 按住 F | 附着墙壁（贴墙时按住即吸附不下滑，松开恢复 wall slide） |
| 按住 C | 悬浮缓降（空中按住大幅降低下落速度；需持有对应技能） |
| Shift（按一下） | 空中冲刺（空中按一下触发横向冲刺；需持有对应技能） |
| **T** | 自杀回最后检查点（卡路时快速重置） |
| **,**（隐藏） | 切换"全图照亮"（调试用：跳过暗影层渲染） |

墙吸附（F）从被动改为主动：贴墙时可选择滑下去（不按 F）或吸附住（按住 F），操作上限更高。打火机（R）持续按住触发，模仿真实打火机手感。

## 四、光源系统

### 4.1 双层视野

| 光源类型 | 半径 | 能耗 | 光色 | 说明 |
|----------|------|------|------|------|
| 默认视野 | 95 px | 无 | 冷色蓝灰微光 | 勉强看到脚下和紧邻地形 |
| 打火机 | **动态 = 230 × √(energy/100) px** | 17 %/秒 | 暖橙色 + 火焰闪烁 | 看清前方地形、怪物、地刺位置 |

**打火机视野随能量衰减**（sqrt 曲线，低能量时下降更陡）：

| 能量值 | 实际光半径 | 衰减幅度 |
|--------|-----------|----------|
| 100% | 230 px | 满 |
| 75% | 199 px | -13% |
| 50% | 163 px | -29% |
| 25% | 115 px | -50% |
| 10% | 73 px | -68% |
| 0% | 0（自动熄灭） | 完全黑暗 |

- 打火机能量上限 100 %，持续使用约 **5.9 秒**耗尽
- 触碰任意检查点（包括已激活的）→ **能量立即回满**（"补给站"机制）
- 打火机开启时有随机火焰闪烁效果（半径波动 ±5%，结合正弦低频 + 随机高频抖动）

设计意图：能量低时光圈缩小，玩家在低能量下既看不清远处又招蚊群，制造"必须冲到下个 CP"的紧迫感。

### 4.2 视野博弈

```
开灯 → 看清地形 + 地刺红色警示 + 驱散暗影
    → BUT 能量持续消耗 + 吸引蚊群围攻 + 暴露玩家位置

关灯 → 节约能量
    → BUT 摸黑攀爬 + 暗影悄然靠近 + 地刺隐入黑暗
```

玩家需要在复杂地形 / 地刺密集区开灯看路，在平坦安全处关灯省电。这种节奏由关卡设计自然调节。

## 五、怪物系统

### 5.1 核心设计：迷雾预警

黑暗中怪物本体不可见，但在玩家视野范围内显示为**彩色光点**：

| 怪物类型 | 光点颜色 | 含义 |
|----------|---------|------|
| **光吸引型** | 小红点 | 开灯会招来它们 |
| **光驱赶型** | 小蓝点 | 关灯它们会靠近 |

玩家看到红点/蓝点，只能知道「附近有什么类型的怪物」，但不知道具体是哪种——保留恐惧感的同时给决策信息。

**技能联动**：
| 技能 | 效果 |
|------|------|
| 暗影感知 | 光点更大更亮 + 蓝点周围显示移动方向 |
| 蚊子驱避 | 红点感知半径 −30% |
| 全图脉冲 | 脉冲瞬间所有光点现形 |

### 5.2 光吸引型（黑暗中 = 小红点）

开灯时被光吸引靠近，关灯后回归漂移状态。

| 怪物 | 移动方式 | 威胁 | 数量 | 首现 |
|------|---------|------|------|------|
| **蚊群** | 光下扑光源绕圈；关灯后正弦漂移回出生点 | 位移干扰 + 屏幕震动（不致死） | 8 群×2-3 只 | 第 8 平台 |
| **飞蛾** | 缓慢直线飘向光源，体积较大 | 贴附在光源前**遮挡视野** | 3-4 只 | 第 12 平台 |
| **光食虫** | 沿平台表面爬向光源 | 附着后每秒吸取 **8% 能量** | 4-5 只 | 第 16 平台 |
| **趋光飞鳞** | 光下快速俯冲撞击 | 击退 + 0.3s 硬直（空中可能坠落） | 3-4 只 | 第 20 平台 |
| **萤火群** | 光下聚集，自身发光 | 形成光团**遮盖玩家自身的光圈** | 3 群×2 只 | 第 24 平台 |

### 5.3 光驱赶型（黑暗中 = 小蓝点）

关灯时靠近玩家，光照下逃逸 / 透明化 / 萎缩。

| 怪物 | 移动方式 | 威胁 | 数量 | 首现 |
|------|---------|------|------|------|
| **暗影** | 黑暗中悄然靠近；光下逃逸透明化（alpha 0.18） | 黑暗中接触 → **秒杀** | 9 只 | 第 12 平台 |
| **藤蔓** | **静止**，黑暗中向邻近平台蔓延生长 | 覆盖平台表面，踩上**减速 50% + 无法起跳**；光下萎缩消失 | 4-5 簇 | 第 16 平台 |
| **伏击蛛** | 黑暗中静止悬挂在**平台底面** | 玩家经过下方 → 垂直下落，无光即死 | 4-5 只 | 第 20 平台 |
| **雾灵** | 黑暗中大面积缓慢漂移（120×80 px 云雾） | 接触持续扣血 10%/s，不致死但逼移动；光下消散 | 2-3 团 | 第 28 平台 |
| **回声蝠** | 黑暗中周期性发出可见**声波圈** | 声波击中 → 0.5s 眩晕 + 暴露位置给周围怪物 | 3-4 只 | 第 24 平台 |

### 5.4 混合型

同时具有吸引和驱赶特性，或在不同光状态下切换行为。

| 怪物 | 行为 | 威胁 | 数量 | 首现 |
|------|------|------|------|------|
| **石瞳** | 开灯时**石化静止**（无害）；关灯时**苏醒追击** | 黑暗中持续追踪，接触即死 | 2-3 只 | 第 32 平台 |
| **光影虫** | 光下透明无害但**吸光充能**；黑暗中发光引爆 | 充能满后即使关灯也会爆炸（范围伤害） | 2-3 只 | 第 36 平台 |

### 5.5 设计维度总览

| 维度 | 变化空间 |
|------|---------|
| **光反应** | 吸引 / 驱赶 / 混合 / 无视光 |
| **移动方式** | 巡逻 / 追击 / 静置伏击 / 周期出现 / 随机游荡 |
| **威胁类型** | 秒杀 / 持续扣血 / 位移干扰 / 遮挡视野 / 能量吸取 / 屏幕特效 |
| **空间位置** | 空中 / 地面 / 平台底面 / 贴墙 / 跨平台穿行 |
| **预警方式** | 红蓝光点 / 音效渐进 / 屏幕边缘变色 |
| **聚合行为** | 单体 / 小群 / 大群 / 怪物间交互 |

### 5.6 总体概要

共 **14 种怪物**，分三大类：

| 类别 | 数量 | 核心博弈 |
|------|------|---------|
| 光吸引型 | 5 种 | 开灯 → 招来怪物；关灯 → 它们安静 |
| 光驱赶型 | 5 种 | 关灯 → 怪物靠近；开灯 → 它们退散 |
| 混合型 | 2 种 | 光态切换带来不同威胁，迫使玩家动态管理 |

早出现的怪物（蚊群、暗影）行为简单，训练基础博弈。中后期怪物引入视野遮挡、能量吸取、底部伏击、区域封锁等新威胁维度。

不存在「安全状态」，只有「选择承受哪种风险」。

## 六、地形与陷阱系统

### 6.0 尺寸标准

所有实体统一基于 **16×16 px 基础网格**，尺寸均为 8px 的倍数。

| 实体 | 尺寸 (px) | 网格单位 |
|------|----------|----------|
| **Tile** | 16 × 16 | 1 × 1 |
| **角色** | 16 × 32 | 1 × 2 |
| **平台** | 宽度可变 × 16 高 | w × 1 |
| **斜坡** | 宽度可变 × 16 高（三角形截面） | w × 1 |
| **墙壁** | 16 × 高度可变 | 1 × h |
| **地刺** | 16 × 10（尖刺区） | 1 × ~0.6 |

**怪物尺寸**：

| 体型 | 尺寸 (px) | 网格 | 包含怪物 |
|------|----------|------|---------|
| 微型 | 8 × 8 | 0.5×0.5 | 蚊群、萤火群 |
| 小型 | 16 × 16 | 1×1 | 飞蛾、光食虫、趋光飞鳞、回声蝠、光影虫 |
| 中型 | 16 × 32 | 1×2 | 暗影、伏击蛛、石瞳 |
| 大型 | 48 × 48 | 3×3 | 雾灵 |
| 特殊 | 可变 | — | 藤蔓（覆盖平台表面，长度可变） |

### 6.1 地形类型

| 类型 | 特性 | 攀爬难度 |
|------|------|----------|
| 平台 | 矩形，水平顶面 | 低 — 可站立、可休息 |
| 斜坡 | 三角形截面，'l'(左高右低) 或 'r'(左低右高) | **中 — 站立即滑下，必须持续操作** |
| 墙壁 | 竖直矩形 | 高 — 需 wall slide + wall jump（仅边界 / 灯塔） |
| 地刺 | 三角形阵列，覆盖平台部分宽度 | **致命 — 任意接触即死** |

### 6.2 物理参数

| 参数 | 数值 | 备注 |
|------|------|------|
| 重力加速度 | 1700 px/s² | 帧率无关 |
| 跳跃初速 | 660 px/s | 起跳瞬间向上 |
| 跳跃极限高度 | ≈ 128 px | `660² / (2·1700)` |
| 地面最大水平速度 | 230 px/s | |
| 地面加速度 | 1600 px/s² | 0→230 用 0.144s |
| 空中加速度 | 800 px/s² | 空中操控较钝 |
| 单跳水平距离 | ≈ 178 px (无 dy) / 152 px (dy=80) | |
| 终端下落速度 | 900 px/s | |
| 土狼时间 | 0.10 s | 离开平台后仍可跳 |
| 跳跃缓冲 | 0.12 s | 落地前按跳依然生效 |

### 6.3 Wall Slide & Wall Jump

- 贴着墙壁按住朝墙方向键 → 减速下滑（Wall Slide），最大下落速度 110 px/s
- 按住 F → 吸附在墙上不下滑（需持有附着墙技能）；不按 F / 松开 F → 恢复 wall slide 下滑
- 在贴墙状态按跳跃 → 反弹跳（Wall Jump），垂直 −627 px/s + 离墙水平 320 px/s
- 当前关卡中墙体仅作为左右边界与灯塔结构，主要用于山顶冲刺技巧

### 6.4 斜坡下滑物理（新）

斜坡不是「静态坡道」，而是「动态压力点」：

| 玩家状态 | 下滑力 | 净加速度 | 体感 |
|---------|--------|----------|------|
| 站立不动（mx=0） | 720 px/s² 沿坡向低端 | 720 | **约 1 秒滑完整段 200 px 斜坡** |
| 主动逆坡爬升 | 360 px/s²（"用脚抓地"，减半） | 1240 | 比平地慢 30%，仍可上 |
| 主动顺坡下行 | 360 px/s² 同方向 | 1960 | 受 max 限制不会失控 |
| 跳起离开斜坡 | 0 | — | 跳跃中无下滑影响 |

实现要点：
- `collideY` 检测斜坡接触时设置 `P.onSlope`：'r' 坡 → `-1`（左下滑），'l' 坡 → `+1`（右下滑）
- `updatePlayer` 在水平加速段根据 `P.onSlope` 施加下滑力
- 滑行速度 |vx| > 40 时每 0.04s 喷出灰褐色尘屑粒子（视觉反馈）

设计意图：
- 玩家从空中落到斜坡低端后必须**立刻**按上坡方向键，否则被滑回平台空隙坠落
- 6 处斜坡（第 5、14、21、30、37、46 平台）成为节奏检查点
- 配合打火机能量博弈：在斜坡上犹豫 = 既耗能又被甩出

### 6.5 地刺陷阱（新）

| 属性 | 说明 |
|------|------|
| 外观 | 暗红 #1e0d0d 三角形阵列（每 7 px 一根尖刺）+ 底座暗影 + 暗灰描边 |
| 致命范围 | AABB 矩形（含 10 px 高度的尖刺区） |
| 黑暗中可见性 | 极弱，几乎与地形混为一体 |
| 打火机光下高亮 | 红色描边随 sin 波脉动 + 尖端 1.5px 高光像素（金属反光） |
| 总数 | 18 处（16 个普通平台 + 山顶大平台两侧 2 个） |
| 分布 | 第 8 平台之前无刺（教学段），后段每 4 平台 1-2 处 |

**安全约束**（保证每个有刺平台仍可通过）：
- 每个有刺平台单侧无刺立足区 ≥ 32 px（玩家宽 16 + 落地误差 16）
- CP 平台（idx 7, 15, 23, 31, 39, 47）完全不放刺
- 斜坡（idx 5, 14, 21, 30, 37, 46）不放刺（视觉/碰撞实现复杂）

**配置模式**：

```
偏左刺  [off=16px, len=64px]  →  左 16 px / 右 80 px  (玩家从左侧起跳难)
偏右刺  [off=80px, len=64px]  →  左 80 px / 右 16 px  (玩家从右侧起跳难)
居中刺  [off=48px, len=64px]  →  左 48 px / 右 48 px
```

设计意图：
- 强化「光-黑暗」博弈：开灯看清刺位置 vs 关灯节能但摸黑踩刺
- 强化"瞄准"动作：跳跃落点不再是「平台任意处」，而要瞄准立足区
- 后段平台双刺布置形成"死胡同陷阱"：玩家若落到错误一侧需要短跳越刺

### 6.6 地图规模（参考值，肉鸽随机生成下会浮动）

- 世界尺寸：**1280 × ~9600 像素**（80 平台 × 平均垂直步进 80px + 边距）
- 主路径：Z 字形 zigzag，x 在 `[280, 560, 820, 540]` 循环
- 平台垂直步进：80 px（约 60% 跳跃极限，128px）
- 平台水平间隙：64 px（4 tile，约 35% 单跳极限）
- 总攀爬距离：**约 6400 px**（起点到山顶）

## 七、检查点系统

- 检查点位置：第 7、15、23、31、39、47 个平台正上方 32 px（共 6 个）
- **首次触碰** → 激活（绿色发光球 + 周围光圈 + 粒子爆发）+ 设为重生点
- **任意触碰**（首次或回访）→ 能量立即回满 100%，伴随轻量绿色尘屑反馈
- 死亡后从最后激活的检查点重生（1.0 秒延迟，黑屏 + 红色震动 + "你死了"提示）
- 终点为山顶灯塔基座上方的金色光柱（半径 40 px 触发），玩家踩上灯塔基座即胜利

**全程可见**：所有检查点（包括未激活的）都在 `renderLighting` 中自带挖光圈，无视黑暗。视觉差异：

| 状态 | 挖光圈半径 | 视觉 |
|------|-----------|------|
| 未激活 | 55 px | 灰白圆圈 + 脉动外环（提示"下一个目标"）|
| 已激活 | 80 px | 绿色发光球 + 绿色彩光晕 |
| 终点 | 130 px | 金色发光球 + 金色脉动彩光 + 灯塔基座 |

**补给站机制**：检查点既是「重生点」也是「能量补给点」。玩家可以在攻坚困难段落时反复返回 CP 充能，但代价是失去前进时间和重新跑路。

## 八、死亡与重生

| 死亡原因 | 惩罚 | 重生位置 |
|----------|------|---------|
| 掉落出世界（y > 6480） | 1.0s 死亡动画 → 重生 | 最后激活的检查点（或起点） |
| 黑暗中接触暗影怪物 | 同上 | 同上 |
| 接触地刺 | 同上 | 同上 |
| 蚊子干扰 | 不掉命，仅位移干扰 + 屏幕震动 + 0.25s 红色 hurt 状态 | — |

### 复活无敌

复活后获得 **2 秒无敌时间**，期间：

- **忽略**地刺、暗影怪、坠落等被动死亡
- **不忽略** T 键自杀（强制 `die(true)` 跳过无敌）
- 视觉反馈：
  - 角色 5Hz 闪烁（透明度 100% ↔ 35% 交替），最后 0.5s 加速到 14Hz
  - 玩家周围浅蓝色保护罩环（呼吸效果）
  - 头顶显示「无敌 X.X」倒计时

设计目的：防止玩家复活后立即踩进同一个地刺或被蹲点的暗影怪秒杀。给玩家一个观察周围、规划路线的缓冲窗口。

注意：**没有进度回退到起点的惩罚**。《掘地求生》的回退惩罚适合直播效果，本作更注重心理压力和策略博弈。最坏情况是回到 8 个平台前的检查点。

## 十一、调试 / 辅助功能

- **T 键自杀**：游戏中按下立即触发 `die()`，1 秒后回到最后激活的 CP。用于卡路、地刺死胡同、走错路的快速回退
- **,（逗号）键全图照亮**：隐藏键（不在 HUD 显示）。切换 `revealAll` 布尔，跳过暗影层渲染让屏幕全亮。玩家依然受所有物理 / 怪物 / 地刺约束，仅视野解锁。屏幕右上角显示 `[ , · 全图照亮 ]` 标记
- **HUD 调试坐标**：屏幕右上角实时显示 `x, y, vx, vy, lightR`（实际光半径）

这些键不是"作弊"，而是设计阶段的辅助。后续可考虑：
- 在正式版本中隐藏（需要按 F1 或特定组合解锁）
- 加入"训练模式"开关，让玩家在熟悉关卡后才能使用

## 十三、肉鸽系统

### 13.1 核心定位

本作**本身就是一款肉鸽like 游戏**，而非通关后才解锁肉鸽模式。每局游戏 = 程序化生成的关卡 + 随机技能成长。

玩家生命周期自然演进：

```
前期（新手）→ 恐惧 + 压力爬塔，在黑暗中摸索，频繁死亡
       ↓ 多局积累
后期（熟手）→ 竞速 + 背板，技能 build 成型后快速闯关
```

**前期靠压迫感拉留存，后期靠竞速和 build 探索拉长尾**。

### 13.2 关卡肉鸽：预制段随机拼接

设计师先设计一批 level chunk（预制段），程序化随机抽选并拼接成完整地图。

#### 预制段数据结构

每个预制段包含：
- 平台序列（含位置、宽度、类型）
- 该段内的地刺布置
- 该段内的怪物 spawn 点
- 斜坡配置

#### 预制段难度分级

每个预制段分配一个难度等级（1-5，可配置）：

| 难度 | 地刺 | 斜坡 | 怪物 | 平台布局 |
|------|------|------|------|---------|
| **1** | 无 | 无 | 无（或仅蚊群） | 标准间距，宽平台 |
| **2** | 单刺 | 无 | 蚊群 + 暗影（少量） | 标准间距 |
| **3** | 单刺/双刺 | 偶有斜坡 | 中等密度 | 标准间距 |
| **4** | 双刺 | 必有斜坡 | 高密度 + 藤蔓/伏击蛛 | 间隙加大 |
| **5** | 双刺 + 窄立足 | 双斜坡或陡坡 | 全种类可能 + 混合型怪物 | 极限间隙 |

#### 入口-出口匹配

当前固定关卡中 x 坐标在 `[280, 560, 820, 540]` 循环。为保证随机段可无缝拼接，每个段定义入口和出口的 x 坐标与行进方向：

```
段类型 A：入口 x=280 → 出口 x=560（右上行）
段类型 B：入口 x=560 → 出口 x=820（右上行）
段类型 C：入口 x=820 → 出口 x=540（左上行）
段类型 D：入口 x=540 → 出口 x=280（左上行）
```

随机抽取时，下一段的入口必须匹配当前段的出口。四个类型构成一个完整的 Z 字形循环。

**每个难度 × 每个方向** 至少 2-3 个变体。首版最低量：5 难度 × 4 方向 × 2 变体 = **40 个预制段**。

#### 总体结构

```
起点教学段（固定，2 段）
  → [难度1 × n1 段]
  → 休息段（过渡：无刺无怪 + CP）
  → [难度2 × n2 段]
  → 休息段（过渡：无刺无怪 + CP）
  → [难度3 × n3 段]
  → 休息段（过渡：无刺无怪 + CP）
  → [难度4 × n4 段]
  → 休息段（过渡：无刺无怪 + CP）
  → [难度5 × n5 段]
  → 休息段（过渡 + 最后一个 CP）
  → 山顶终点段（固定，1 段）
```

**配置参数**（n1-n5 可调，以下为推荐默认值）：

| 参数 | 默认值 | 每段约平台数 | 总平台数 |
|------|--------|------------|----------|
| n1 | 3 段 | ~6 | ~18 |
| n2 | 3 段 | ~6 | ~18 |
| n3 | 3 段 | ~5 | ~15 |
| n4 | 2 段 | ~5 | ~10 |
| n5 | 2 段 | ~4 | ~8 |
| 休息段 | 5 段 | 1 平台 | 5 |
| 起点 + 终点 | 3 段 | — | ~8 |

**总长约 80 个平台**（相比原固定关卡的 48 个，增长约 67%）。

**检查点分布**：5 个休息段各放 1 个 CP + 终点 = 6 个 CP，正好对应技能 T1/T2/T3 三段。

**设计意图**：
- 休息段作为难度过渡的「透气点」，同时充当 CP+技能选择
- 难度递进保证前期（难1-2）给新手学基础、后期（难4-5）给熟手压力
- n1-n5 可配置：竞速模式可缩短、新手模式可加长难度1

### 13.3 段落主题标签

每个预制段附带标签，程序化抽取时做二次调控：

**主题标签**：

| 标签 | 特征 |
|------|------|
| 地刺密集 | 该段地刺数量 ≥ 3 |
| 斜坡挑战 | 含 1-2 处斜坡 |
| 怪物遭遇 | 蚊子/暗影/藤蔓等密集分布 |
| 伏击 | 含伏击蛛或石瞳等底部/出其不意怪物 |

**随机规则**：
- 同一难度级内，不连续抽到相同的预制段
- 同一难度级内，主题标签尽量不连续重复（如连续 2 段「地刺密集」→ 第 3 段避开）
- 难度递进由段位分层结构保证（难1→难2→...），无需额外检查

### 13.4 构筑维度全景

局内成长的构筑从 **五个维度** 切入，覆盖核心循环的每个环节：

| 维度 | 核心问题 | 定位 | 示例技能 |
|------|---------|------|---------|
| **移动能力** | 「怎么爬」 | 核心，改变操作手感 | 二段跳、附着墙、悬浮缓降、空中冲刺 |
| **光源/信息** | 「怎么看」 | 核心，改变信息获取 | 光圈增益、能耗降低、全图脉冲 |
| **生存/容错** | 「怎么活」 | 辅助兜底 | 复活一次、无敌延长、地刺预警 |
| **资源经济** | 「怎么管能量」 | 辅助数值向 | 被动回能、击杀回能、能量上限 +15% |
| **怪物交互** | 「怎么应对怪」 | 辅助数值/机制向 | 蚊子眩晕光环、暗影退散、光爆震退 |

前三个维度对应「爬→看→活」的核心循环，手感变化明显。后两个维度偏数值向，提供微调空间但不喧宾夺主。

### 13.5 技能获取机制：段位分层 + Tag 软引导

采用 **B（段位分层）+ C（Tag 软引导）混合** 的方式控制技能获取节奏：

#### 段位分层（保证前期不乱、后期有惊喜）

每个检查点从对应 Tier 的技能池中 3 选 1。T1 打基础，T2 出流派核心，T3 出终极能力：

| 段位 | 对应检查点 | 池子定位 |
|------|-----------|---------|
| **T1** | CP 1-2 | 基础技 — 泛用性强，确定本局方向 |
| **T2** | CP 3-4 | 进阶技 — 流派成形，部分有前置依赖 |
| **T3** | CP 5-6 | 终极技 — 质变能力，build 完全体 |

#### Tag 软引导（引导专注但不锁死）

#### Tag 软引导（引导专注但不锁死）

每个技能带 tag。玩家选择了某个 tag 的技能后，后续选项中出现同 tag 技能的概率 +30%。

```
tag 示例：
  [移动]、[光源]、[生存]、[经济]、[怪物]

拿了二段跳 [移动] → 下个 CP 出现空中冲刺/附着墙跳跃的概率 ↑
拿了光圈+25% [光源] → 下个 CP 出现锥形光/能耗降低的概率 ↑
```

#### 移动技特殊规则

- **不重复出现**：移动技一旦被选取，从后续所有段位池中永久移除
- **T1 互斥**：#1 二段跳 与 #2 附着墙 互斥，选了其一另一个立即从池中移除
- **跨池联动**：持有某个移动技可能解锁 T2/T3 的前置条件，但选择权仍在玩家手中

软引导的好处：玩家自然形成专精 build，但运气差时也能跨系补位，不会一条路走到黑。

```
                └── 持有 #1 或 #2 都可解锁 #6

#3 悬浮缓降 ──→ #8 缓降增强 (T2)

#4 空中冲刺 ──→ #9 冲刺无敌 (T3)
```

光源链：

```
L3 全图脉冲 ──→ L4 脉冲冷却 −0.5s (T2, 可重复)
       └──→ L7 脉冲冷却 −3s (T3)

脉冲冷却路线：
  初始 15s → T2 最多 −1s（选 L4 ×2）→ T3 −3s（L7）→ 最短 11s（下限 3s 永不触及）

L1 光圈 +10% ──→ L5 光圈 +30% (T3) → 叠到 +40%
L2 能耗 −10% ──→ L6 能耗 −30% (T3) → 叠到 −40%
```

经济链（无前置，无限叠加）：

```
E1 能量上限 +15% (T1) — 单次延长约 0.9s 开灯时间
E2 被动回能 0.5%/s (T2) — 叠 4 次后基本覆盖开灯消耗
```

生存链：

```
复活一次 ──→ 无敌延长 (T3)
```

怪物链：

```
暗影感知 ──→ 暗影退散光环 (T3)
任意 [怪物] 技 ──→ 光爆震退 (T3)
```

### 13.8 单局 Build 示例

```
「空中穿梭」build：
  T1 #1 二段跳 → T2 #4 空中冲刺 → T2 #6 冲刺不断跳 → T3 #9 冲刺无敌
  体验：二段跳 + 可中断冲刺 + 冲刺无敌，空中自由穿梭且冲刺窗口无敌

「墙壁旅者」build：
  T1 #2 附着墙 → T2 #5 附着墙跳跃 → T2 #6 冲刺不断跳 → T3 #9 冲刺无敌
  体验：贴墙吸附 → 墙面起跳 → 空中冲刺，墙壁变成起点而非终点

「精准控制」build：
  T1 #3 悬浮缓降 → T2 #4 空中冲刺 → T2 #8 缓降增强 → T2 #7 冲刺可中断
  体验：精确控制落点 + 可中断冲刺，一帧一帧微调位置

「光明使者」build：
  T1 L1 光圈+10% → T2 L2 能耗−10% → T3 L5 光圈+30% → T3 L6 能耗−30%
  体验：光圈 +40%、能耗 −40%，视野几乎无焦虑，但移动仍是基础款

「脉冲竞速」build：
  T1 L3 全图脉冲 → T2 L4 脉冲冷却×2 → T3 L7 脉冲冷却−3s
  体验：打火机几乎废了（−70%），但每 11s 一次全屏透视，适合背板后竞速

「能量永动」build：
  T1 E1 能量上限×2 → T2 E2 被动回能×2 → 再叠更多 E2
  体验：能量几乎用不完，开灯自由，但移动和视野都是基础款
```

### 13.9 平衡底线

- 同类辅助技最多叠加 3 层（如移速 +15% × 3 = +45%），**经济系除外**（E1/E2 无限叠加）
- 所有移动技不重复出现（T1-T3 每个 [移动] 技能全局限 1 次）
- 数值全部用加法，避免乘法膨胀
- T3 池确保至少 2 个无前置技能，保证非酋也有好选择
- 每局最多 6 个技能（6 个检查点）

### 13.10 局外成长（Meta Progression）

局外成长提供长线目标，**横向扩展为主**，不产生数值碾压：

- **光之碎片**：每次通关或到达一定高度获得
- **用途**：
  - 解锁新技能进卡池（增加 build 多样性）
  - 提升初始能量上限（小幅度，上限明确）
  - 解锁新角色皮肤 / 打火机外观
  - 解锁「挑战模组」（如：全程无检查点、蚊子翻倍、暗影一击必杀）

### 13.11 肉鸽与生命周期的关系

| 玩家阶段 | 对肉鸽的感知 | 核心体验 |
|----------|-------------|----------|
| 新手前几局 | 地图陌生 + 技能不熟 → 探索感、恐惧感 | 压力爬塔，靠少量技能勉强生存 |
| 中期多局 | 开始熟悉段类型 + 技能组合 → build 探索 | 尝试不同移动技 combo，找到偏好流派 |
| 后期熟手 | 段类型已背板 + 技能池全解锁 → 竞速 | 追求最优路线 + 最优 build，挑战速通纪录 |

同一套肉鸽系统支撑了从「恐惧爬塔」到「竞速背板」的完整生命周期。

## 十四、商业化策略

### 14.1 双线发行

| 维度 | 小游戏端（IAA） | Steam 端 |
|------|-----------------|----------|
| 商业模式 | 广告变现 | 买断制（一次性付费） |
| 目标用户 | 泛用户、碎片时间 | 核心玩家、平台跳跃/肉鸽爱好者 |
| 定价 | 免费 | 待定（参考同类：Jump King ¥36, Getting Over It ¥29） |
| 内容差异 | 完整游戏 + 广告系统 | 完整游戏，无广告 |
| 开发优先级 | 先行（国内小游戏生态验证玩法） | 后发（Steam 需更高完成度与本地化） |

### 14.2 小游戏端广告设计

核心原则：**不影响核心体验，变现点放在便利性和局外成长加速上**。

| 广告类型 | 触发场景 | 频率控制 |
|----------|---------|----------|
| 激励视频 | 死后原地复活一次（非回检查点） | 每局限 1 次 |
| 激励视频 | 技能选择时额外刷新一次（3 选 1 → 重新随机） | 每检查点限 1 次 |
| 激励视频 | 局外成长双倍光之碎片 | 每日限 3 次 |
| 插屏广告 | 死亡回检查点后弹出 | 每 5 次死亡触发 1 次 |
| Banner 广告 | 暂停菜单底部 | 常驻，不影响游戏画面 |

**设计原则**：
- 前 3 局仅展示 Banner，不弹插屏，保护新手体验
- 所有激励视频不强制，纯「便利性增益」——玩家愿意也可以完全靠技术通关
- 不卖数值、不卖能量、不卖技能——确保「公平竞技」感

### 14.3 Steam 端差异化

- 去掉所有广告相关代码和 UI
- 加入 Steam 成就系统（如：无技能通关、15 分钟内通关、全程不开灯通关）
- 云存档 + 排行榜（竞速排名）
- 可能的 DLC：新主题关卡包、新怪物种类、手电筒模式
- 支持创意工坊？玩家自制预制段分享

### 14.4 风险与优势

| 优势 | 风险 |
|------|------|
| 小游戏先跑验证核心玩法，降低 Steam 冷启风险 | 双端代码维护成本 |
| IAA 提供持续收入，不依赖 Steam 首周爆发 | 小游戏端广告体验设计不当会劝退 |
| 玩法本身（直播效果好）适合 Steam 自然传播 | 掘地求生产品类型在 Steam 已属小众 |
| 肉鸽化后小游戏端留存天然高于线性关卡 | IAA + 买断制两套商业化需分开管理 |

**建议节奏**：小游戏端先上线跑数据（留存、广告 ARPU、通关率），根据数据调优后再启动 Steam 移植。

## 十五、技术实现

### 15.1 架构
- 纯 HTML5 Canvas + JavaScript，**单文件零依赖**
- 物理：完全帧率无关（所有运算基于 `dt` 秒级时间）
- 渲染：单 Canvas + 1 个离屏 darkCanvas（用于光照合成）
- 静态资源：1 个 800×600 预渲染星空 Canvas

### 15.2 物理引擎
- **碰撞**：分轴 AABB 扫描（先 X 后 Y），斜坡用底部中心点采样 `slopeTopY` 精确吸附
- **跳跃**：土狼时间 + 跳跃输入缓冲，业界标准平台手感
- **斜坡下滑**：`P.onSlope` 状态 + 水平加速度叠加，主动移动减半下滑力
- **wall slide / wall jump**：贴墙检测角色边缘距墙壁 ≤ 2px（`Math.abs((P.x+P.w) - t.x) < 2` 或 `Math.abs(P.x - (t.x+t.w)) < 2`）

### 15.3 光照系统
```
1. darkCanvas 全屏填充 rgba(4,5,10, 0.88)
2. globalCompositeOperation = 'destination-out'
3. 在玩家位置、打火机偏移位置、检查点位置挖光圈（径向 gradient）
4. 主 Canvas drawImage(darkCanvas)
5. globalCompositeOperation = 'lighter' 加色光晕（暖橙 + 冷蓝 + 检查点彩光）
```

### 15.4 关卡构建
- 路径数据由常量 `PATH_XS / PATH_WS / PATH_DY` 程序化生成 48 个平台
- 斜坡映射 `slopes = {5:'r', 14:'l', 21:'r', 30:'l', 37:'r', 46:'l'}`
- 地刺布置数组 `[idx, off_ratio, len_ratio]`，确保单侧立足 ≥ 40 px
- 怪物 spawn 用 `pathCx(i) / pathTop(i)` 计算位置，关卡变更自动跟随

### 15.5 AI 状态机

```
通用层 — 迷雾光点渲染:
  if 怪物在玩家视野范围内:
    if 光吸引型 → 渲染为小红点
    if 光驱赶型 → 渲染为小蓝点
    (本体不可见，仅光点可见)

光吸引型 AI:
  蚊子:   光开且近 → 扑光源绕圈 | 光关 → 正弦漂移回出生点
  飞蛾:   光开且近 → 直线飘向光源贴附(遮挡视野) | 光关 → 远离
  光食虫: 光开且近 → 沿平台爬向玩家 | 光关 → 静止
  趋光飞鳞: 光开且近 → 俯冲撞击(击退+硬直) | 光关 → 缓慢巡游
  萤火群: 光开且近 → 聚集+发光遮盖光圈 | 光关 → 分散

光驱赶型 AI:
  暗影:   光开且近 → 逃逸透明化 | 光关且近 → 靠近秒杀 | 其余 → 游荡
  藤蔓:   光开且近 → 萎缩消失 | 光关 → 蔓延生长覆盖平台
  伏击蛛: 光开 → 静止(可见) | 光关且玩家经过下方 → 下落 | 其余 → 悬挂
  雾灵:   光开且近 → 消散 | 光关 → 大面积漂移(区域封锁)
  回声蝠: 光关 → 周期性发射声波圈 | 光开 → 远离

混合型 AI:
  石瞳:   光开 → 石化静止(无害) | 光关 → 苏醒追击(秒杀)
  光影虫: 光开 → 透明+吸光充能 | 充能满 → 黑暗中发光引爆(范围伤害)
```
