# Fresh Toast ImageGen prompts

Mode: built-in ImageGen. The Timeline fresh day badge was supplied as a style and palette reference only.

All source generations used genuine-transparent-background instructions. Because the generator returned a baked neutral checkerboard, the selected artwork was converted to RGBA by deriving alpha from neutral border pixels, trimming to the alpha bounds, adding four transparent safety pixels, and checking the final alpha channel before Unity import.
