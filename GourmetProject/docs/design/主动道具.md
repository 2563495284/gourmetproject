# 主动道具

## 调味小票

- 仅能在未结算的 `Food` 美食战斗主界面使用。
- 点击使用后，以世界空间贝塞尔箭头选择桌上有有效菜谱来源的一道菜；无来源临时菜不进入候选。
- 甜 / 苦 / 鲜 / 麻 / 酸 / 咸分别由六种调味小票追加。
- 成功后当前实例立即刷新风味表现，并按 `FoodFlavorLimit` 的追加/替换规则写回当前 Run 的来源 `RecipeBookSlot`；真正落盘仍由战斗结束后的既有存档节点负责。
- `t_numb` 当前只追加并播放变化动画，不旋转已经摆好的菜；后续旋转规则留待补充。

## 铺台小票

- 仅能在未结算的 `Food` 美食战斗主界面使用。
- 使用时选择一个存在的餐桌格；空格与被菜品覆盖的格都可选择。
- 瞄准期间桌上菜品降至原透明度的 50%，退出时精确恢复。
- 樱桃木 / 胡桃木 / 大理石 / 黑曜石 / 翡翠 / 金 / 银分别由七种铺台小票追加。
- 成功后同时更新当前 `BattleSession.DiningTable` 与当前 Run 的格子材质覆盖，不在主动道具层直接存档。

## 共同交互

- 点击道具先打开含 `ItemTipView` 完整信息、术语卡、不可用原因、使用与丢弃按钮的操作气泡。
- 点击使用后隐藏鼠标，显示从道具图标中心出发的 19 段二次贝塞尔目标箭头。
- 有效目标高亮；单击后立即应用并消费，不再出现确认层。
- 右键、Esc、界面切换、无效点击、对象销毁、应用失败或成功都会统一清理箭头、高亮、透明度、点击状态与鼠标状态。
- 数据修改与道具消费只更新当前内存；动画只负责表现，落盘统一遵循既有存档节点。

## 排程小票

### 行动调整单

- 重掷一次当前行动选项，Boss 行动除外

### 盛宴调整单

- 重新随机本周 Boss Debuff

### 加急单

- 立即执行行动轴上的下一个节点行动

### 奖励单

- 添加一个奖励节点，到时间轴上
