# 消耗品

## 调味小票

- 仅能在未结算的 `Food` 经营挑战主界面使用。
- 点击使用后，以世界空间贝塞尔箭头选择桌上有有效食谱来源的1 个食物；无来源临时菜不进入候选。
- 甜 / 苦 / 鲜 / 麻 / 酸 / 咸分别由六种调味小票追加。
- 成功后当前实例立即刷新风味表现，并按 `FoodFlavorLimit` 的追加/替换规则写回当前 Run 的来源 `RecipeBookSlot`；真正落盘仍由经营挑战结束后的既有存档节点负责。
- `t_numb` 对已经摆好的菜生效时，从食物当前朝向开始按配置步数逆时针旋转，变化完成后飞入临时桌。
- 临时桌可同时保存多道菜；临时菜不占主餐桌空间，也不参与预览分数、结算技能、邻接或范围判定。
- 临时菜与出菜口的待摆菜互不阻塞。临时菜拖回餐桌只做固定朝向重定位，不增加上菜次数、不重复触发 OnServe，也不改变出菜口状态。
- 点击「吃」时允许临时桌仍有菜；这些食物不参与本次结算，原上菜时已经产生的副作用不回滚。

## 铺台小票

- 仅能在未结算的 `Food` 经营挑战主界面使用。
- 使用时选择一个存在的餐桌格；空格与被食物覆盖的格都可选择。
- 瞄准期间桌上食物降至原透明度的 50%，退出时精确恢复。
- 樱桃木 / 胡桃木 / 大理石 / 黑曜石 / 翡翠 / 金 / 银分别由七种铺台小票追加。
- 成功后同时更新当前 `BattleSession.DiningTable` 与当前 Run 的格子材质覆盖，不在消耗品层直接存档。

## 共同交互

- 点击装饰品和消耗品先打开含 `ItemTipView` 完整信息、术语卡、不可用原因、使用与丢弃按钮的操作气泡。
- 点击使用后隐藏鼠标，显示从装饰品和消耗品图标中心出发的 19 段二次贝塞尔目标箭头。
- 有效目标高亮；单击后立即应用并消费，不再出现确认层。
- 右键、Esc、界面切换、无效点击、对象销毁、应用失败或成功都会统一清理箭头、高亮、透明度、点击状态与鼠标状态。
- 数据修改与装饰品和消耗品消费只更新当前内存；动画只负责表现，落盘统一遵循既有存档节点。

## 排程小票

### 行动调整单

- 重掷一次当前行动选项，Boss 行动除外

### 星级评鉴调整单

- 重新随机本周 Boss Debuff

### 未来复制单 / 过往复制单

- 只能在普通行动选择或节点行动选择时使用。
- 未来复制单选择一个未来未执行节点；过往复制单选择一个过去已执行节点，并把其行动复制到当前或下一个整数日。
- 在整数天使用时复制到当天；在非整数天使用时复制到下一个整数天。
- 装饰品和消耗品不会打断当前选择：普通行动完整结算后检测复制节点；节点行动完整结算后动态重扫并依次执行同日节点，直到没有到期节点才返回普通行动选择。

### 奖励单

- 添加一个奖励节点，到时间轴上
