# 行动轴

![行动轴原型图](./行动轴.png)

- 单局游戏持续多周(配置)，一周为一个阶段，以行动轴展示
- 在每一周，玩家不断进行**行动**n选一，决定下一个**行动**，并消耗对应天数
- 行动结束后，若到行动轴特殊节点，会执行特殊事件

## 初始行动轴

- 一个七天的轴，在整天上可能会有特殊节点
- 进度条结束时，会进入下一周，或者游戏胜利
- 长度可能收到道具、角色、事件影响

## 节点事件

### 特殊的事件类型，展示在行动轴上，一般包括如下几种

- Boss：带有特殊机制的**美食**
- 收取利息：根据当前的金币数，每满n金币获得1金币
- 进入商店：商店中有各种可出售物品
- 等等：待补充更多事件

### 执行顺序

- 在执行完行动后，若进度条前进的区域内有节点事件，会进行结算这些节点事件

### 行动轴随机

- 根据角色，预设多种行动轴库，根据权重进行随机
- 每种配置包含的节点事件（Boss除外）

### Boss随机

- 按权重随机，部分boss需要满足特殊条件解锁
- 根据角色，随机可能随机出来的boss
- 带有特殊机制
