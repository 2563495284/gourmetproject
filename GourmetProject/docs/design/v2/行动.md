# 行动

玩家进入游戏后

## 行动从外观上分类（以下为大致分类，可能会分更细）

- 消耗天数按照行动进行配置（随机范围，带最小步进）
- 美食（奖励金币）
- 美食（奖励碎片）
- 美食（奖励被动道具）
- 美食（奖励菜品）
- 美食（奖励主动道具）
- 美食（奖励被动道具）（更难）
- 美食（奖励碎片）（更难）
- 美食（奖励道具）（更难）
- 美食（奖励菜品）（更难）
- 美食（奖励主动道具）（更难）
- 事件
- 奖励

## 行动类型

行动类型分为：

- 事件：
  - 前置条件：完成此事件的前置条件，才有概率随机出
  - 权重：随机到此类事件的权重
    - 部分事件满足某些条件时，权重走一个序列（每次随机时走下一个事件）
    - 部分事件不可重复随机到
  - 分类：奖励事件、负面事件、美食事件等等
  - 事件会需要玩家选择选项，事件结果也会因为选项而不同
    - 选项中可能会有美食、奖励、buff等各种
- 美食：也就是局内玩法。
  - 外观上会根据固定奖励分为多种图标
  - 根据难度，会分为两种，奖励也会不同
  - 进入局内，完成要求的分数，获得奖励
- 奖励：  
  - 小概率出现，只随机奖励事件
