# 食物

## 属性

### 所占空间

- 每个食物都会占**网格**，不同食物形状不一样
- **棋盘**放的下此食物时（食物可旋转），才有可能被随机到
- **食物**从**食谱**中随机出来的规则是：通过随机权重发射（随机权重线形比于所占格子数）

### 基础分数（美味值）

- 各种结算参与计算

### 风味

- 不同风味有不同效果
- 每个食物最多有一个风味，若再次获得，会替换原来的风味。
- 特殊装饰品和消耗品可以解除只能存在单个风味的设定

### 技能

- 每种食物初始都有一个技能（配置）。
- 单个食物拥有的技能数量无上限
- 食物的技能被添加、修改

## 食物库

- 纯配置的随机食物库
- 每个食物都有一个隐藏分范围，以及基础权重，价格
- 取上下限为隐藏分均值
- 食物，食物带标签A，视为两个食物，拥有不同的隐藏分范围

### 随机食物

- 每当需要一个食物展示给玩家选择或获得时，会根据当前的进度、事件修正、纯随机修正，确立一个要求隐藏分
- 去随机食物库中，查看隐藏分范围包括此要求隐藏分的食物，有概率被随机出来
- 每个食物的食物权重为要求隐藏分a和隐藏分均值b差值的函数w=基础权重/max「|a-b|，c」（c根据不同进度，是一个常数值）
- 同时展示多个食物时，需不放回随机（若全部取完，则全部放回再随机）
