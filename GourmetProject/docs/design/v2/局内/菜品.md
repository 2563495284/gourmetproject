# 菜品

## 属性

### 所占空间

- 每个菜品都会占**网格**，不同菜品形状不一样
- **棋盘**放的下此菜品时（菜品可旋转），才有可能被随机到
- **菜品**从**菜单**中随机出来的规则是：通过随机权重发射（随机权重线形比于所占格子数）

### 基础分数（美味度）

- 各种结算参与计算

### 风味

- 不同风味有不同效果
- 每个菜品最多有一个风味，若再次获得，会替换原来的风味。
- 特殊道具可以解除只能存在单个风味的设定

### 技能

- 每种菜品初始都有一个技能（配置）。
- 单个菜品拥有的技能数量无上限
- 菜品的技能被添加、修改

## 菜品库

- 纯配置的随机菜品库
- 每个菜品都有一个隐藏分范围，以及基础权重，价格
- 取上下限为隐藏分均值
- 菜品，菜品带标签A，视为两个菜品，拥有不同的隐藏分范围

### 随机菜品

- 每当需要一个菜品展示给玩家选择或获得时，会根据当前的进度、事件修正、纯随机修正，确立一个要求隐藏分
- 去随机菜品库中，查看隐藏分范围包括此要求隐藏分的菜品，有概率被随机出来
- 每个菜品的菜品权重为要求隐藏分a和隐藏分均值b差值的函数w=基础权重/max「|a-b|，c」（c根据不同进度，是一个常数值）
- 同时展示多个菜品时，需不放回随机（若全部取完，则全部放回再随机）
