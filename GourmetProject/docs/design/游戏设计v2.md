# 行动

## 行动从外观上分类

- 美食（奖励金币）
- 美食（奖励碎片）
- 美食（奖励道具）
- 美食（奖励菜品）
- 美食（奖励道具）（更难）
- 美食（奖励碎片）（更难）
- 美食（奖励道具）（更难）
- 美食（奖励菜品）（更难）
- 事件
- 奖励

## 行动选择

- 行动不是预生成序列；每次打开周地图时实时从 `action` 表筛选可用行动。
- 可用行动条件：
  - 前置条件满足。
  - 不可重复行动本周没有用过。
  - 后续可扩展角色、难度、行动池、周进度等限制。
- 筛选后按 `weight` 不放回随机生成本次选项。
- 本次展示是 n 选一：候选不足时可以是 1/2 选一，最多展示 3 个。
- 玩家选择 1 个行动后，行动按 `costDays` 推进行动轴天数游标，并检查经过的行动轴节点。

## 行动轴节点

- 行动轴只负责“第几天经过什么节点”，不预生成玩家行动序列。
- 节点按天数升序结算；一次行动跨过多个节点时逐个处理。
- 节点类型：
  - 利息：按金币阈值发放金币。
  - 商店：进入商店，关闭后继续结算后续节点。
  - 事件：触发事件效果；事件可以是即时收益/惩罚，也可以派生美食挑战、直接失败、直接胜利等后续流程。
  - Boss：触发本周 Boss 战。

## Boss 周规则

- 最后一周是终极 Boss。
- 非最后一周是普通 Boss；普通 Boss 胜利后直接进入下一周。
- 终极 Boss 胜利后本局胜利。
- Boss 失败按常规失败结算。

## 分数与奖励

### 局内奖励

    - 金币上下限分别为美食难度(普通、难、boss)和进度的一个函数，纯随机

## 隐藏分计算方式

### 基础隐藏分

- 基础隐藏分=f【游戏进度（天数），行动加成，道具加成】
- 可能分多段

### 分数

- 分数=f【基础隐藏分，行动加成，道具加成】
- 可能分多段

### 菜品隐藏分

- 菜品隐藏分=f【基础隐藏分，行动加成，道具加成】
- 可能分多段

### 道具隐藏分

- 菜品隐藏分=f【基础隐藏分，行动加成，道具加成】
- 可能分多段

## 胃部碎片隐藏分

- 菜品隐藏分=f【基础隐藏分，行动加成，道具加成】
- 可能分多段

## 初始菜谱生成

- 菜谱配置 `requiredInitScore` 作为随机停止阈值。
- 随机池条目 `RecipeEntry` 使用 `dishId,weight,maxCount,initScore`，其中 `initScore` 是本菜谱内初始分。
- 初始分不再放在菜品基础属性里；同一道菜在不同菜谱中可以配置不同初始分。
