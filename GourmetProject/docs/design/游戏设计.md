# 游戏设计（总览索引）

本文档已按主题拆分为 [`游戏设计/`](./游戏设计/) 目录下的模块文件。本页作为索引与总览，各模块详情见对应链接。

本项目是基于 GameFramework 的小丑牌-like 肉鸽游戏：玩家以“周”为阶段推进，每周一条时间轴，从整局行动组序列的当前行动组中 n 选一执行；局内核心是通过食谱上菜、在胃部棋盘摆放食物并结算标签与装饰品和消耗品效果。
