# 游戏设计v3

## 分数与奖励

### 局内分数

- 由难度和游戏进度（第几周，第几天）决定一个初始值
- 可以通过难度标签、boss机制、主动/被动道具等修正分数

### 局内奖励

- 局内奖励为金币+菜品+特定奖励（菜品、道具、碎片）
  - 特定奖励是选择行动时预览的奖励
- 金币
  - 金币上下限分别为金币奖励隐藏分，按照上下浮动n%，随机得到
- 菜品、被动道具、碎片
  - 根据菜品、道具、碎片隐藏分，去随机
- 主动道具
  - 纯随机
- 菜品、道具、碎片，需要支持n选m

## 整局流程线

### 行动

#### 行动从外观上分类（以下为大致分类，可能会分更细）

- 美食（奖励金币）
- 美食（奖励碎片）
- 美食（奖励被动道具）
- 美食（奖励菜品）
- 美食（奖励主动道具）
- 美食（奖励被动道具）（更难）
- 美食（奖励碎片）（更难）
- 美食（奖励道具）（更难）
- 美食（奖励菜品）（更难）
- 美食（奖励主动道具）（更难）
- 事件
- 奖励

#### 行动组合

- 配置多种行动的组合（不一定是三个），配置行动和时间随机范围，举例如下
  - 普通美食组：美食（奖励金币）+美食（奖励碎片）+美食（奖励道具）
  - 普通更难美食组：美食（奖励金币）+美食（奖励碎片）+美食（奖励道具）（更难）
  - 事件美食组：事件+美食（奖励道具）
  - 纯奖励组：奖励
- 纯静态随机，随机出一个序列，例如普通美食组-普通更难美食组-纯奖励组-........
  - 按照优先级，根据确定部分行动组合，其余通过纯随机组合
    - 例如第一，我希望纯奖励组会在第3-6个行动出现一次，10-12个行动出现一次
    - 第二，我希望事件组能在每10个行动中的第2-8个行动，随机出现1～2个
    - 剩下的按照权重随机，保证连续两次不出现相同的行动组
