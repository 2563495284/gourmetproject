# 分数、隐藏分与奖励

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「8. 分数、隐藏分与奖励」。相关：[食物](./食物.md)、[装饰品和消耗品](./装饰品与消耗品.md)、[棋盘](./餐桌.md)。

## 基础隐藏分

隐藏分用于控制局内难度、食物与餐桌格奖励投放；装饰品改用独立运气：

- 基础隐藏分 = f（游戏进度、行动加成、装饰品和消耗品加成）。
- 游戏进度通常由周数、天数、本周行动序号或整局行动序号决定。
- 行动加成来自行动类型、行动难度、事件结果或 星级评鉴机制。
- 装饰品和消耗品加成来自装饰品、消耗品和特殊风味效果。
- 具体函数按配置分段选择；同一用途可配置多条曲线段，并按周范围、整局行动序号范围和优先级匹配。

## 派生隐藏分

不同系统基于基础隐藏分派生各自的要求值：

- 目标美味值 = f（基础隐藏分、行动加成、装饰品和消耗品加成）。
- 食物隐藏分 = f（基础隐藏分、行动加成、装饰品和消耗品加成）。
- 装饰品运气 = 基础值 + 周进度 + 当周天数进度 + 装饰品/事件/奖励槽修正。
- 餐桌格隐藏分 = f（基础隐藏分、行动加成、装饰品和消耗品加成）。

目标美味值用于经营挑战达标判断。食物和餐桌格隐藏分用于筛选候选；装饰品不再使用隐藏分区间，而是先按运气抽 Common / Uncommon / Rare / Epic 品质，再在品质内按单品权重抽取。消耗品只按单品权重抽取。

## 局内奖励

局内奖励类型包括金币、n 选 m 食物、n 选 m 装饰品、消耗品、n 选 m 餐桌格等。一般结构为：金币 + 一个选择行动时可预览的特定奖励 + 随机附加奖励。

金币规则：

- 金币一般都会发放，是购物、刷新等系统的通用货币。
- 金币上下限由食物难度和游戏进度共同决定。
- 在上下限范围内随机取值。
- 若奖励随机池完全为空，部分奖励可折算为金币，并输出配置警告。

非金币奖励规则：

- 食物奖励使用食物隐藏分随机。
- 装饰品奖励使用统一两阶段选择器；空品质先剔除，同批多抽不放回。Negative 仅显式诅咒入口可抽，Legendary 暂不使用。
- 消耗品按来源和特殊标记纯随机，随机时放回；仍受持有上限影响。
- 餐桌格奖励使用餐桌格隐藏分随机。
- 食物、装饰品和餐桌格同时展示多个候选时不放回随机；如果候选不足则展示较少数量或按配置折算金币。
