# 开始准备与经营方向

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「3. 开始准备与经营方向」。

每个经营方向需要配置：

| 字段 | 说明 |
|---|---|
| 初始被动/消耗品 | 经营方向进入单局时自带的装饰品和消耗品 |
| 初始食谱 | 当前经营方向的初始食谱配置 |
| 食物随机池 | 当前经营方向可随机到的食物集合，当前阶段可通过食谱和解锁条件间接表达 |
| 装饰品和消耗品随机池 | 当前经营方向可随机到的装饰品和消耗品集合，当前阶段可通过特殊标记和解锁条件表达 |
| 初始餐桌格 | 初始胃形状来源 |
| 胃部最大大小 | 最大长宽，影响可扩展边界 |
| 时间轴库 | 当前经营方向可随机到的时间轴集合，空表示全部 |

进入单局时，先按经营方向初始化：

1. 初始食谱和固定/随机食物。
2. 初始胃部棋盘和最大扩展边界。
3. 初始装饰品和消耗品。
4. 金币、周数、天数、行动次数和已触发记录。
5. 当前周时间轴。
