# 上菜与结算

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「11. 上菜与结算」。相关：[棋盘](./餐桌.md)、[食物](./食物.md)、[装饰品和消耗品](./装饰品与消耗品.md)、[食物与 Boss](./食物与星级评鉴.md)。

## 上菜

1. 根据棋盘空位，筛选出可以被塞入棋盘的食物。
2. 食物允许 90 度任意翻转。
3. 根据权重，从可塞入棋盘的食物中随机。权重正比于这些食物初始的格子数，也可以被装饰品和消耗品等效果修正。
4. 每个菜只可以被上一次，除非有特定标签或装饰品和消耗品效果。

## 技能与风味结算

1. 若无特殊效果，按照从上到下、从左到右确立所有棋盘格的结算顺序。
2. 多个棋盘格为同一个食物时，只在第一次结算该食物的技能与风味，格子标签可以结算多次。
3. 单道食物内的结算顺序：先结算全部技能，再结算风味，最后结算所占格子的格子标签。

## 分数结算

若无特殊标签，按照从上到下、从左到右的顺序，把所有分数加合作为总分数。消耗品、装饰品、标签和 星级评鉴机制可以在最终结算前追加加法、乘法或达标修正。
