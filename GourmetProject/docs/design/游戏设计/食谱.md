# 初始食谱

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「9. 食物、食谱与随机食物」中的食谱部分。相关：[食物](./食物.md)、[经营方向准备](./经营方向准备.md)。

- 每局只维护一个食谱，并根据所选经营方向初始化。
- 初始食谱会配置一些固定食物。
- 初始食谱中部分食物并非固定，开局前展示初始食谱可能包含的食物种类，部分食物需要解锁。
- 可随机食物分成多个小组，每个小组有独立的带权随机池。
- 食谱配置多套「各小组抽取数量数组」，每套数组另配权重；开局先按权重选择一套数量方案，再按小组顺序抽取指定数量。
- 小组内按权重放回随机，部分食物通过 `maxCount` 限制最多被随机的次数。
- `RecipeEntry` 格式为 `dishId,weight,maxCount`；数量方案数组项按食谱的 `groupIds` 顺序与小组一一对应。
