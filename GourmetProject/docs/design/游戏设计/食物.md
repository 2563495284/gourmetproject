# 食物与随机食物

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「9. 食物、食谱与随机食物」中的食物部分。相关：[食谱](./食谱.md)、[棋盘](./餐桌.md)、[上菜与结算](./上菜结算.md)、[隐藏分与奖励](./隐藏分与奖励.md)。

## 食物属性

食物是类似装饰品和消耗品的构筑对象，主要属性包括：

- 占空间：以格子为基础的空间占据，不同食物形状不同；食物可旋转，棋盘放得下时才可能被随机到。
- 基础分数（美味值）：用于技能结算以及美味值结算。
- 风味：每个食物最多一个风味。
- 技能：每个食物的技能数量无上限。

## 风味

- 不同风味有不同效果。
- 每个食物最多有一个风味，若再次获得，会替换原来的风味。
- 特殊装饰品和消耗品可以解除「只能存在单个风味」的设定。

## 技能

- 每种食物初始都有配置好的技能。
- 单个食物拥有的技能数量无上限。
- 食物的技能可以被添加、修改。

风味与技能涉及游戏专有名词时，需要额外展示说明。

## 食物库与随机食物

食物库是纯配置的随机食物库。每个食物都有隐藏分范围、基础权重和价格；隐藏分均值取上下限均值。同一本体带不同风味 / 技能组合视为不同食物，拥有不同的隐藏分范围。

每当需要一个食物展示给玩家选择或获得时：

1. 根据当前进度、行动修正、事件修正、装饰品和消耗品修正和随机修正，确立要求隐藏分。
2. 从食物库中筛选隐藏分范围包含该要求隐藏分的食物。
3. 每个食物权重为要求隐藏分 `a` 和隐藏分均值 `b` 差值的函数：`w = 基础权重 / max(|a-b|, c)`。
4. 同时展示多个食物时，不放回随机；若全部取完，则全部放回再随机。
