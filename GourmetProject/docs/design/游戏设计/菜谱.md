# 初始菜谱

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「9. 菜品、菜谱与随机菜品」中的菜谱部分。相关：[菜品](./菜品.md)、[角色准备](./角色准备.md)。

- 初始会根据每个角色设立一个初始菜谱。
- 初始菜谱会配置一些固定菜品。
- 初始菜谱中部分菜品并非固定，开局前展示初始菜谱可能包含的菜品种类，部分菜品需要解锁。
- 可随机菜品分成多个小组，每个小组有独立的带权随机池。
- 菜谱配置多套「各小组抽取数量数组」，每套数组另配权重；开局先按权重选择一套数量方案，再按小组顺序抽取指定数量。
- 小组内按权重放回随机，部分菜品通过 `maxCount` 限制最多被随机的次数。
- `RecipeEntry` 格式为 `dishId,weight,maxCount`；数量方案数组项按菜谱的 `groupIds` 顺序与小组一一对应。
