# 专有名词解释

## 行动统一模型术语

详见 [行动系统](./行动.md)。核心术语：

- **原子行动（Action）**：游戏中一切「会发生的事」的唯一基础单元，表现一致（卡片），执行按行为分派。是一层**薄壳**：只保存 behavior + 关联明细/少量参数，具体内容在明细表（`TbFood` / `TbEvent`）。
- **来源（Source）**：行动如何进入游戏。`Placed`=放置在时间轴节点、到达该天自动触发；`Random`=推进日程时按行动数袋、类别和奖励逐卡随机 n 个供玩家 n 选 1；`Rest`=兜底休息。
- **行为（Behavior）**：行动做什么。`Food`（含 Boss）/ `Event` / `Reward` / `Negative` / `Shop` / `Interest`。
- **食物明细（TbFood）**：Food 行为的具体内容表，含日常营业/火热营业/星级评鉴（`actionKind`）。承载目标美味值倍率、金币曲线、奖励包、隐藏分、debuff、Boss 解锁条件与随机权重等；难度差异全在此表（曲线表不再有难度档列）。
- **事件明细（TbEvent + TbEventOption）**：Event/Reward/Negative 三行为共用；`eventTypes` 是可用 `|` 配置的有序多分类列表，全部分类参与池匹配、首项作为主分类；公共字段为 `preconditions/weight/repeatable`，选项结果用 `EffectType` 枚举。
- **行动数洗牌袋**：按周把 2/3 张候选的整数权重展开成票并洗牌；逐组消费、袋空重装、换周重置，重掷也消费。
- **类别/奖励逐卡随机**：每张候选先抽 Daily/Hot/Event，再为营业类别抽 `RewardKind`；两层都按本周候选卡序号做累计上下保底。

旧 → 新术语映射：

| 旧概念 | 新统一术语 |
|---|---|
| 行动内联 payload/难度/曲线等 | 薄壳 `TbAction` + 明细表 `TbFood` |
| 独立 `TbBoss` | 并入 `TbFood`（`actionKind=Feast`） |
| `behavior=Event` 内联正文/选项（`TbActionOption`） | 独立 `TbEvent` + `TbEventOption`（按 `eventId`） |
| `foodDifficulty`（Normal/Hard/Boss 字符串） | `TbFood.actionKind`（Normal/Super/Feast） |
| 效果字符串（effectType） | `EffectType` 枚举 |
| `TbActionGroup` / `TbActionSmallGroup` / `TbActionLargeGroup` | `TbActionChoiceCountRule` + `TbActionCategoryRule` + `TbActionRewardRule` |
| `action_schedule_rule` 窗口预排 | 类别/奖励按周、逐候选卡累计 `minGuaranteeCounts` / `maxGuaranteeCounts` |
| 行动/成员上的 `costDays` | 行动 `min/maxCostDays`（随机本次耗时） |

## 其它

- 甜蜜传递：使随机食物获得此技能<br>并结算其获得的<br>所有甜蜜传递技能

- 美味值=基础分x倍率

- 周围：与食物网格共边相邻的网格

- 同行：食物网格所在行（所有网格所在行都算）

- 同列：食物网格所在列（所有网格所在列都算）

- 判断A食物和B食物的位置关系时，可以以A食物为基准，判断B食物的每一个格子与A食物的关系，然后合并
