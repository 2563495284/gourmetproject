# 专有名词解释

## 行动统一模型术语

详见 [行动系统](./行动.md)。核心术语：

- **原子行动（Action）**：游戏中一切「会发生的事」的唯一基础单元，表现一致（卡片），执行按行为分派。是一层**薄壳**：只保存 behavior + 关联明细/少量参数，具体内容在明细表（`TbFood` / `TbEvent`）。
- **来源（Source）**：行动如何进入游戏。`Placed`=放置在行动轴节点、到达该天自动触发；`Random`=推进日程时两层行动组随机 n 个供玩家 n 选 1；`Rest`=兜底休息。
- **行为（Behavior）**：行动做什么。`Food`（含 Boss）/ `Event` / `Reward` / `Negative` / `Shop` / `Interest`。
- **美食明细（TbFood）**：Food 行为的具体内容表，含普通/超级/盛宴（`actionKind`）。承载目标分倍率、金币曲线、奖励包、隐藏分、debuff、Boss 解锁条件与随机权重等；难度差异全在此表（曲线表不再有难度档列）。
- **事件明细（TbEvent + TbEventOption）**：Event/Reward/Negative 三行为共用；`eventType` 分类，公共 `preconditions/weight/repeatable`；选项结果用 `EffectType` 枚举。
- **两层行动组**：小组（固定成员=n 选一，`weight` 供大组挑选）→ 大组（多个小组；`ruleIds` 参与日程规则 + `fallbackWeights[周-1]` 保底加权）。

旧 → 新术语映射：

| 旧概念 | 新统一术语 |
|---|---|
| 行动内联 payload/难度/曲线等 | 薄壳 `TbAction` + 明细表 `TbFood` |
| 独立 `TbBoss` | 并入 `TbFood`（`actionKind=Feast`） |
| `behavior=Event` 内联正文/选项（`TbActionOption`） | 独立 `TbEvent` + `TbEventOption`（按 `eventId`） |
| `foodDifficulty`（Normal/Hard/Boss 字符串） | `TbFood.actionKind`（Normal/Super/Feast） |
| 效果字符串（effectType） | `EffectType` 枚举 |
| `TbActionGroup` + `TbActionGroupMember`（单层，成员带权重） | 两层：`TbActionSmallGroup`（含 weight）+ `TbActionLargeGroup` |
| `action_schedule_rule.groupIds`（规则持候选组） | 大组 `ruleIds` 反向引用规则 |
| 行动/成员上的 `costDays` | 行动 `min/maxCostDays`（随机本次耗时） |

## 其它

- 甜蜜传递：使目标食物获得并结算此技能

- 美味值=基础分x倍率

- 周围：与菜品网格相邻的网格

- 同行：菜品网格所在行（所有网格所在行都算）

- 同列：菜品网格所在列（所有网格所在列都算）

- 判断A食物和B食物的位置关系时，可以以A食物为基准，判断B食物的每一个格子与A食物的关系，然后合并
