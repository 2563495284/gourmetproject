# 商店系统

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「13. 商店系统」。相关：[道具](./道具.md)、[菜谱](./菜谱.md)、[行动轴](./行动轴.md)。

## 商店刷新

商店根据当前周、天数、行动上下文和隐藏分刷新商品。商店商品包括：

- 菜品。
- 主动道具。
- 被动道具。
- 胃部碎片。

商品建议字段：

| 字段 | 说明 |
|---|---|
| item_id | 商品 ID |
| item_type | 菜品 / 主动道具 / 被动道具 / 胃部碎片 |
| price | 价格 |
| hidden_score_range | 隐藏分区间 |
| weight | 随机权重 |
| stock | 库存 |

## 商店操作

玩家在商店中可以：

- 购买商品。
- 编辑菜谱。
- 删除菜品。
- 关闭商店并回到行动轴流程。

删除菜品需要花费金币。商店关闭后继续处理剩余行动轴节点；若没有剩余节点，则回到 n 选一行动。
