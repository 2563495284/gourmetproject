# 棋盘（胃）

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「10. 棋盘（胃）」。相关：[上菜与结算](./上菜结算.md)、[食物](./食物.md)、[隐藏分与奖励](./隐藏分与奖励.md)。

## 大小

- 每个经营方向有一个固定的初始胃部大小，可能会根据食谱变化。
- 每个经营方向都有一个胃部最大大小，设定为长 `n`、宽 `m`。

## 餐桌格库

- 配置一个餐桌格库。
- 碎片在棋盘编辑页可用鼠标滚轮旋转（0/90/180/270°），存在格与强化格标签一同旋转；配置表只需给出一种朝向。
- 部分餐桌格可能带有强化标签，分开配置。
- 每个餐桌格有自身权重、隐藏分范围和价格。
- 隐藏分均值取隐藏分上下限的均值。

## 随机餐桌格

在需要展示或给玩家餐桌格奖励时：

1. 检测玩家的最大胃部大小和当前胃部大小。
2. 若已达到最大胃部大小，将碎片按隐藏分分段线性折算为金币。
3. 若未达到最大胃部大小，从餐桌格库中筛选可以放入当前胃部扩展范围、且隐藏分范围包含要求隐藏分的碎片。
4. 每个碎片权重为要求隐藏分 `a` 和隐藏分均值 `b` 差值的函数：`w = 基础权重 / max(|a-b|, c)`。
5. 同时展示 3 个但只有 2 个符合要求时，展示 2 个。
6. 如果经过筛选后仍随机不到，输出配置错误，提示策划排查。

## 扩展胃部

- 扩展胃部时通过 UI 直接限制玩家，若扩展后大于最大长宽，则不能扩展。
- 扩展胃部必须贴着原来的胃部扩展，不能分割开来。
- 商店碎片区出售「碎片包」：购买后进入棋盘编辑页（世界空间），开出 3 个候选形状，玩家三选一、滚轮旋转、悬停高亮可放/不可放，点击落位；落位受最大网格（局部空间）限制，且必须贴边相邻、不重叠。
- 编辑页拼贴结果以 `(碎片 id, 旋转, 原点)` 记录进存档，可复现重建胃形；右键放弃则将碎片包按隐藏分折算金币兜底。
