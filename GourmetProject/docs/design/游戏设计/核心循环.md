# 核心循环

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「1. 核心定位」「2. 单局主循环」。

## 核心定位

玩家在一局中以“周”为阶段单位推进。每周是一条时间轴，时间是主要局外行动资源；整局开始后按配置生成一条行动组合序列，玩家每次从当前行动组合给出的 n 个行动中选择 1 个执行（最多 3 个，候选不足时可以少于 3 个），行动消耗天数并推进 7 天游标。行动可能进入经营挑战、事件、奖励或商店；如果推进区间经过时间轴节点，则按天数顺序触发利息、商店、事件或 Boss。

局内核心是通过食谱上菜，在胃部棋盘中摆放食物并结算食物标签、格子标签和装饰品和消耗品效果。经营挑战达成目标美味值后获得金币、食物、装饰品、消耗品或餐桌格等奖励；任意食物或 Boss 挑战失败则游戏失败；最终周 Boss 胜利则游戏通关。

核心资源关系：

- 食物：类似装饰品和消耗品的构筑对象，提供形状、分数和标签。
- 食谱：决定可被上菜随机系统抽取的食物集合。
- 胃部棋盘：决定食物摆放空间、格子标签和扩展边界。
- 装饰品和消耗品：提供局级、上菜、标签结算、最终结算、奖励和商店阶段的修正。
- 金币：商店购买、刷新、编辑和删除食物的通用货币。
- 隐藏分：控制目标美味值、食物、装饰品和消耗品、餐桌格和商店商品的投放节奏。
- 行动组合序列：控制整局行动选择节奏、奖励外观和难度节奏。
- 时间轴：控制一周内的时间游标和特殊节点节奏。

## 单局主循环

```mermaid
flowchart TD
  StartRun["开始单局"] --> SelectCharacter["选择经营方向"]
  SelectCharacter --> InitRun["初始化食谱、胃、装饰品和消耗品、金币"]
  InitRun --> WeekStart["进入当前周"]
  WeekStart --> RollTimeline["随机本周时间轴"]
  RollTimeline --> ChooseAction["读取当前行动组合并生成 n 选一行动"]
  ChooseAction --> ExecuteAction["执行选择的行动"]
  ExecuteAction --> AdvanceDays["按 costDays 推进天数"]
  AdvanceDays --> CollectNodes["收集经过的时间轴节点"]
  CollectNodes --> ResolveNodes["按天数顺序结算节点"]
  ResolveNodes --> WeekFinished{"时间轴走完?"}
  WeekFinished -->|"否"| ChooseAction
  WeekFinished -->|"是"| NextWeek["进入下一周"]
  NextWeek --> WeekStart
  ExecuteAction -->|"食物失败"| Defeat["失败结算"]
  ResolveNodes -->|"最终 Boss 胜利"| Victory["胜利结算"]
```

关键规则：

1. 一周对应一条时间轴，默认 7 天。
2. 每次行动选择来自整局行动组合序列的当前行动组；组内候选按权重不放回随机，最多 3 个。
3. 行动执行后先推进天数，再检测经过的节点。
4. 一次行动经过多个节点时，按时间轴从前到后的顺序依次结算。
5. 节点是系统节奏，不是行动本身；行动和节点都可以引导到事件、商店、食物或 Boss。
6. 经营挑战未达目标美味值立即失败。
7. 普通 Boss 胜利后立即进入下一周。
8. 最终周 Boss 胜利立即进入胜利结算。
9. 普通周时间轴走完后进入下一周。
