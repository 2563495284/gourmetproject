# 行动系统

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「4. 行动系统」。相关：[行动轴](./行动轴.md)、[事件](./事件.md)。

## 行动模型口径

当前口径是整局级行动组合序列：一局运行中先按配置规则生成行动组序列，每次选择行动时读取当前整局行动序号对应的行动组，再从该组成员中筛选满足前置条件的行动并按权重不放回随机 n 个行动，最多展示 3 个。行动组负责控制奖励外观、难度节奏和事件/奖励插入节奏；行动本身负责具体结算内容、前置条件、隐藏分修正和默认耗时。

行动至少包含：

| 字段 | 说明 |
|---|---|
| action_id | 行动唯一 ID |
| action_type | 行动类型：美食、事件、奖励、负面、商店等 |
| cost_days | 消耗天数 |
| weight | 默认随机权重；组成员未覆盖时可作为兜底 |
| preconditions | 出现前置条件 |
| repeatable | 是否可重复出现；不可重复行动本周命中后不再进入池 |
| payload | 行动具体结算内容 |
| food_difficulty | 美食难度：普通、困难、Boss 等 |
| reward_kind | 美食胜利后的主奖励外观与奖励池类型 |
| reward_package | 美食胜利后的奖励包 |
| gold_curve | 金币奖励曲线 |
| hidden_score_bonus | 行动对隐藏分和目标分的额外修正 |

行动组合至少包含：

| 字段 | 说明 |
|---|---|
| group_id | 行动组唯一 ID |
| group_type | 外观分类，例如普通美食组、困难美食组、事件美食组、纯奖励组 |
| week_filter | 可出现周筛选：普通周、Boss 周、指定周或空 |
| weight | 填充普通序列空位时的随机权重 |
| preconditions | 行动组出现前置条件 |

行动组成员至少包含：

| 字段 | 说明 |
|---|---|
| group_id | 所属行动组 |
| action_id | 指向具体行动 |
| weight | 组内候选随机权重 |
| min_cost_days / max_cost_days | 本次行动耗时随机范围；为空或小于等于 0 时使用行动默认 `cost_days` |

## 行动类型

行动从外观和奖励结果上分为：

- 美食（奖励金币）。
- 美食（奖励胃部碎片）。
- 美食（奖励被动道具）。
- 美食（奖励主动道具）。
- 美食（奖励菜品）。
- 更难美食（奖励金币 / 胃部碎片 / 道具 / 菜品）。
- 事件。
- 奖励。
- 负面事件。
- 商店。

美食行动的难度至少包含普通、困难、Boss。难度会参与目标分、金币范围和各奖励随机池隐藏分的计算。

## 行动随机

整局行动组合序列生成规则：

1. 根据角色、周筛选和行动组前置条件得到可用行动组。
2. 先按 `ActionScheduleRule` 的优先级填充指定整局行动序号窗口。例如纯奖励组在第 3-6 个行动出现 1 次、第 10-12 个行动出现 1 次。
3. 同一规则可配置窗口内出现次数、最小/最大次数和候选行动组池。
4. 剩余空位按行动组权重随机填充。
5. 默认保证连续两次不出现相同的行动组；若候选不足，则允许打破该限制并输出配置警告。
6. 运行态保存已生成的行动组序列和整局行动序号，读档后不重新抽已确定部分。

每次打开行动选择界面时：

1. 读取当前整局行动序号对应的行动组；若序列长度不足，则继续按规则扩展生成。
2. 从行动组成员表得到候选行动。
3. 筛选满足行动前置条件的行动。
4. 排除本周已命中的不可重复行动。
5. 对组成员按 `weight` 不放回随机最多 3 个；候选不足时展示 1/2 个。
6. 每个候选会生成本次行动选择快照，包括行动 ID、行动组 ID、整局行动序号、本周行动序号和覆盖后的耗时。
7. 若无可选行动，允许休息行动作为兜底，消耗 1 天。

## 行动执行

行动执行顺序：

```text
选择行动
  ↓
创建 ActionExecutionContext（包含行动组、整局序号、耗时快照）
  ↓
根据 cost_days 推进当前天数
  ↓
记录本周行动次数、整局行动次数和不可重复行动
  ↓
按 action_type 执行行动结果
  ↓
结算经过的行动轴节点
  ↓
回到下一行动组的 n 选一 / 进入下一周 / 结算胜负
```

行动执行结果：

| 类型 | 结果 |
|---|---|
| Food | 进入美食挑战，使用行动难度、奖励包、金币曲线和隐藏分修正生成目标与奖励 |
| Event | 打开指定事件，或由事件服务按权重随机事件 |
| Reward | 直接结算奖励或效果 |
| Negative | 直接结算负面效果 |
| Shop | 打开商店 |
