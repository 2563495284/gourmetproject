# 装饰品和消耗品

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「12. 装饰品和消耗品」。相关：[隐藏分与奖励](./隐藏分与奖励.md)、[商店](./商店.md)、[上菜与结算](./上菜结算.md)。

## 术语

1. 装饰品和消耗品定义：配置表中的静态数据，包含名字、描述、图标、类型、品质、特殊标记、权重、效果与上限。
2. 装饰品和消耗品状态：单局运行中的持有数据。装饰品同一 id 唯一一份，不升级也不重复持有；消耗品同一 id 可持有多份，每份是一个独立实例。
3. 获得装饰品和消耗品：把一个装饰品和消耗品定义结算到装饰品和消耗品状态上。装饰品只允许首次获得，若因兜底或旧流程重复结算则折算金币；消耗品表现为新增一份实例，到达持有上限则折算金币或重抽。
4. 随机池：某次奖励、事件或商店刷新可被抽取的装饰品和消耗品集合。所有随机都走统一筛选与权重，避免不同系统规则漂移。

## 装饰品

装饰品参数：

- 技能：具体能力是什么，由效果类型和参数描述。
- 品质：表征稀有度与投放节奏。
- 特殊标记：可能在某些事件、星级评鉴奖励或流派定向奖励中被随机到。
- 随机权重：基础出现权重，之后可被品质分布、隐藏分和来源规则修正。
- 解锁条件：部分装饰品和消耗品一开始不会解锁，需要满足指定条件。

装饰品触发：

- 构建经营挑战时：修改本局棋盘、食谱、目标美味值、上菜次数等局级参数。
- 上菜前后：修改候选菜权重、额外生成菜、改变摆放结果。
- 标签结算前后：追加风味效果、修改某类菜的分值。
- 最终结算前：追加最终加法、乘法或达标修正。
- 奖励/商店刷新时：修改奖励池、价格、品质分布或额外选项。

## 消耗品

消耗品参数：

- 技能：具体能力是什么，由效果类型和参数描述。
- 特殊标记：可能在某些事件以及 星级评鉴奖励中被随机到。
- 触发时机：在某些阶段可以触发，例如上菜前、上菜后、吃之前、结算后、奖励界面。
- 持有上限：当前同时最多持有几份实例。
- 使用即移除：消耗品使用后该实例直接从持有列表移除。

消耗品随机与 UI：

- 消耗品随机时放回；同一批次或连续批次都允许抽到同一消耗品，只要没有达到持有上限。
- 简单消耗品点击后立即生效，例如清空棋盘、额外上菜。
- 复杂消耗品点击后进入选择模式，例如选择一个菜、一个格子或一本食谱。
- 不满足触发时机时置灰，并展示不可用原因。
- 同一 id 的多份实例在 UI 上聚合为一个槽，用角标 xN 表示份数。

## 统一随机规则

所有奖励、事件、商店都使用统一随机池。

筛选顺序：

1. 类型筛选：装饰品/消耗品。
2. 解锁筛选：未解锁的装饰品和消耗品不进入池。
3. 来源筛选：特殊事件只允许指定特殊标记。
4. 隐藏分筛选：当来源配置要求装饰品和消耗品隐藏分时，只保留隐藏分范围包含要求值的装饰品和消耗品。
5. 持有筛选：已持有的装饰品、达到持有上限的消耗品不进入池。

权重计算：

- 基础权重来自配置。
- 品质分布由来源决定，例如普通奖励、星级评鉴奖励、商店、特殊事件。
- 若使用装饰品和消耗品隐藏分，权重可叠加要求隐藏分和装饰品和消耗品隐藏分均值差值的修正。

同时展示多个装饰品时，不放回随机；消耗品随机时放回。如果随机范围内没有装饰品和消耗品：

- 先扩大到同来源的全部品质。
- 再没有时扩大到整个已解锁装饰品和消耗品库。
- 仍然没有时折算为金币，并输出配置警告。
