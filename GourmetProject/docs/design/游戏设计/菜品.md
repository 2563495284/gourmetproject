# 菜品与随机菜品

> 拆分自 [游戏设计总览](../游戏设计.md)，对应原文档「9. 菜品、菜谱与随机菜品」中的菜品部分。相关：[菜谱](./菜谱.md)、[棋盘](./棋盘.md)、[上菜与结算](./上菜结算.md)、[隐藏分与奖励](./隐藏分与奖励.md)。

## 菜品属性

菜品是类似道具的构筑对象，主要属性包括：

- 占空间：以格子为基础的空间占据，不同菜品形状不同；菜品可旋转，棋盘放得下时才可能被随机到。
- 基础分数（美味度）：用于技能结算以及最终分数结算。
- 风味：每个菜品最多一个风味。
- 技能：每个菜品的技能数量无上限。

## 风味

- 不同风味有不同效果。
- 每个菜品最多有一个风味，若再次获得，会替换原来的风味。
- 特殊道具可以解除「只能存在单个风味」的设定。

## 技能

- 每种菜品初始都有配置好的技能。
- 单个菜品拥有的技能数量无上限。
- 菜品的技能可以被添加、修改。

风味与技能涉及游戏专有名词时，需要额外展示说明。

## 菜品库与随机菜品

菜品库是纯配置的随机菜品库。每个菜品都有隐藏分范围、基础权重和价格；隐藏分均值取上下限均值。同一本体带不同风味 / 技能组合视为不同菜品，拥有不同的隐藏分范围。

每当需要一个菜品展示给玩家选择或获得时：

1. 根据当前进度、行动修正、事件修正、道具修正和随机修正，确立要求隐藏分。
2. 从菜品库中筛选隐藏分范围包含该要求隐藏分的菜品。
3. 每个菜品权重为要求隐藏分 `a` 和隐藏分均值 `b` 差值的函数：`w = 基础权重 / max(|a-b|, c)`。
4. 同时展示多个菜品时，不放回随机；若全部取完，则全部放回再随机。
