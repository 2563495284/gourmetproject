## 经营挑战

经营挑战行动会进入局内挑战：

1. 根据周配置、行动难度、行动隐藏分、当前天数、行动次数、装饰品、消耗品和事件修正生成目标美味值。
2. 玩家通过食谱上菜并在胃部棋盘结算分数。
3. 分数大于等于目标美味值则挑战成功，进入奖励界面。
4. 分数低于目标美味值则游戏失败。

经营挑战行动建议字段：

| 字段 | 说明 |
|---|---|
| food_id | 食物或行动 ID |
| icon_type | 图标类型，依据固定奖励分类 |
| difficulty_variant | 难度变体 |
| target_score | 目标美味值曲线或覆盖值 |
| reward | 达成奖励 |
| fail_condition | 失败条件，默认未达目标美味值 |

## Boss

星级评鉴是特殊节点驱动的经营挑战。

星级评鉴随机规则：

1. 根据 星级评鉴自身 `unlockCondition` 过滤。
2. 从未抽取 星级评鉴候选中按权重随机。
3. 当前候选取光后，重置 星级评鉴抽取历史并重新从全部可用 星级评鉴中随机。
4. 星级评鉴可覆盖目标美味值曲线和特殊机制。

星级评鉴配置建议字段：

| 字段 | 说明 |
|---|---|
| boss_id | Boss ID |
| role_pool | 可出现经营方向池 |
| unlock_conditions | 解锁条件 |
| weight | 随机权重 |
| week | 阶段标记（不参与 星级评鉴随机筛选） |
| food_config | 星级评鉴对应的经营挑战配置 |
| special_mechanics | Boss 特殊机制 |
