# 中文术语规范

本规范适用于项目自有代码中的中文字符串与注释、Unity 序列化文本、配置源 Excel、生成配置、GM、测试和文档。英文类名、枚举名、字段名、配置 ID、资源 ID 与存档字段不因本规范改名。

## 使用规则

- “营业”只包含日常营业与火热营业，不包含星级评鉴。
- “丢弃”只指经营挑战内从出菜口临时丢弃；“删除”只指从食谱永久移除。
- 倍率效果写成 `倍率 +0.1` 或 `倍率 ×1.5`，玩家文案不使用“乘区”。
- 数字与中文单位之间留空格：`20 金币`、`1 个食物`、`3 次营业`、`1 颗红心`。
- 范围使用 `20～140`；选择简写使用 `2 选 1`；完整句写“从 2 个食物中选择 1 个”。
- 比较使用 `≤`、`≥`；百分号紧跟数字。
- 事件卡保留“突发事件 / 幸运事件”，商店卡保留“商店采购”，利息卡保留“收取利息”。
- 玩家定位固定为：“玩家是一名餐厅老板，选择经营方向，打造独具特色的餐厅。”
- 通关文案固定为：“你的经营方向达到顶峰，餐厅名扬四海！”

## 专名与技术例外

- 保留专名“美食街”。
- 保留动词“出菜”“上菜”。
- 保留专名“丰收菜篮”“家常菜挂画”“开胃菜”“黄铜传菜铃”“加菜券”。
- “祖传食谱残页”“抽页食谱夹”“可擦食谱板”“活页食谱册”“缺角食谱板”为正式名称。
- 普通汉语中不代表游戏 `Character` 的“角色”可按原义使用。
- 技术符号可保留 `Battle`、`Boss`、`Character` 等英文标识；玩家可见的 `Boss` 必须写“星级评鉴”。
