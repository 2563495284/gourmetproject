# GourmetProject 配置表说明

> 面向 **策划 / 美术 / 程序** 的统一配置词典。
> 目标：任何人拿到这份文档，不用翻代码也能看懂「每张表是干什么的、每个字段填什么、值会流向哪里」。

- **配置源**：`GameConfig/Datas/*.xlsx`（schema 与数据都在 Excel 里，**不写 JSON 源数据**）。
- **生成产物（勿手改）**：代码 → `Assets/GameMain/Scripts/Config/Gen/`；运行时数据 → `Assets/StreamingAssets/Config/*.json`。
- **生成命令**：`bash GameConfig/gen.sh`（需要 .NET SDK 8.0+）。
- **运行时访问**：统一走 `GameApp.Config.Tables.TbXxx.Get(id)`。
- **记录数**：本文中各表的「记录数」为 2026-06-25 生成时的数据行数，仅供参考，会随表更新变化。

## 1. 给三个工种的快速指引

| 角色 | 你主要关心 | 怎么读这份文档 |
| --- | --- | --- |
| **策划** | 数值、概率、解锁、节奏 | 直接看每张表的字段表与「填写提示」，重点是 `weight / 曲线 / 区间 / preconditions`。 |
| **美术** | 资源路径字段 | 搜索 `icon / portrait / 图标 / 立绘`，这些字段填资源路径，命名规范见各表备注。 |
| **程序** | 数据流向、消费方 | 看每张表的「出处与引用」，里面列出读取该表的运行时服务。 |

改字段记住三件事：① 在数据 xlsx 改表头（`##var`/`##type`/`##comment`）；② 在 `__tables__.xlsx` 登记（仅新增表时）；③ 跑 `gen.sh`。详见 [`.cursor/rules/luban-config.mdc`](../.cursor/rules/luban-config.mdc)。

## 2. 配置体系总览

```
GameConfig/Datas/*.xlsx ──(luban.conf)──> bash GameConfig/gen.sh ──┬─> Config/Gen/*.cs   (Tables 访问层)
                                                                   └─> StreamingAssets/Config/*.json (运行时数据)
                                                                            │
                                                          ProcedurePreload 整局加载一次
                                                                            │
                                                          GameApp.Config.Tables.TbXxx
```

挂载关系来自 [`GameConfig/luban.conf`](../GameConfig/luban.conf)：

| schema 文件 | 类型 | 作用 |
| --- | --- | --- |
| `Defines/builtin.xml` | — | 框架自带（vec2/vec3 等），玩法不碰 |
| `Datas/__enums_*.xlsx` | enum | 枚举定义（按主题拆多个文件，如 tag/item/reward/action/unlock/dish） |
| `Datas/__beans__.xlsx` | bean | 复合单元格子结构（`RecipeEntry` 等） |
| `Datas/__tables__.xlsx` | table | **表登记**：一行=一张表 |

## 3. 阅读约定

### 3.1 数据表表头三行
每个数据 sheet 的首列单元格用 `##` 标记行类型，字段结构「直接读表头」：

| 标记行 | 含义 |
| --- | --- |
| `##var` | 字段名（程序里的属性名） |
| `##type` | 字段类型（**结构来源**） |
| `##comment` / `##` | 字段注释（会进生成代码的文档） |

### 3.2 类型写法

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `string` `int` `float` `bool` | 基础类型 | `42` / `3.5` / `true` |
| 枚举名 | 见 [第 6 节枚举字典](#6-枚举字典)，填**枚举名字符串** | `Passive` `Boss` |
| `list,string` | 字符串数组（多行模式，字段名前加 `*`） | 形状/标签列表 |
| `list,Bean` | 复合元素数组，每元素一个单元格，靠 bean 的 `sep` 切分 | `rice,150,0,5` |
| `Bean` | 单个复合值，一个单元格按 `sep` 切分 | `min,max` |

### 3.3 多元素 list（多行模式）
字段名前加 `*`（必须是最后一列）。每个元素占一行，**续行所有前导列留空**，靠主键列是否为空区分记录。例：`dish_base` 的 `*shapeRows`、`recipe` 的 `*pool`。

### 3.4 空值约定
- 字符串「空串」通常表示「无 / 任意 / 不限」，各表会在说明里点明（如 `weekFilter` 空=任意周、`characterPool` 空=任意角色）。
- 数值字段约定多见 `<=0 表示不限/使用默认`，以字段说明为准。

## 5. 逐表字段说明

> 字段表的「类型」与枚举/bean 链接到 [第 6 节](#6-枚举字典) / [第 7 节](#7-bean复合单元格字典)。
> 资源路径字段（`icon`/`portrait`）由美术维护。

### 5.1 菜品 / 技能 / 风味 / 格子标签

#### TbDishBase — 菜品本体
菜品不随技能/风味变化的物理属性。形状用 `*shapeRows` 多行字符串描述，`'X'` 表示占用格。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 菜品基础ID（主键） |
| name | string | 菜品名称 |
| deliciousness | int | 基础美味度（基础分） |
| icon | string | 图标资源路径（美术） |
| allowRotate | bool | 是否允许旋转摆放 |
| `*shapeRows` | list,string | 菜品形状，每行一字符串，`'X'`=占用格（多行模式） |

> **填写提示**：sprite 尺寸按格子原生尺寸生成（1x1=512²、2x1=1024×512、2x2=1024²），纯食品不拟人化，见 [`food-asset-style.mdc`](../.cursor/rules/food-asset-style.mdc)。

#### TbDishVariant — 菜品变体（随机库条目）
引用本体 + 风味/技能组合 + 隐藏分/权重/价格。**同 baseId 不同风味/技能组合视为不同菜品**。`flavorId` 空串=无风味（风味槽为空）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 变体ID（主键） |
| baseId | string | 引用的菜品本体ID → `TbDishBase.id` |
| flavorId | string | 风味ID（可空，单槽）→ `TbFlavor.id` |
| baseWeight | float | 随机基础权重 |
| price | int | 商店价格 |
| hiddenRange | [HiddenRange](#hiddenrange) | 出现隐藏分区间，单元格写 `min,max` |
| rotation | [DishRotation](#dishrotation) | 固定旋转朝向（整格四向）；`allowRotate=false` 时自动上菜只用该朝向 |
| `*skills` | list,string | 技能ID列表（无上限）→ `TbSkill.id`（多行模式） |

#### TbSkill / TbFlavor / TbCellTag — 技能 / 风味 / 格子标签
三张表结构完全相同（效果字段与效果引擎共用），仅按概念拆分：**技能**挂在菜品上、数量无上限；**风味**挂在菜品上、单槽后者替换前者；**格子标签**挂在胃碎片格上（`TbFragmentCellTag` 引用）。`termId` 非空时菜品详情额外展示该名词。运行时分别经 `GameplayDatabase.GetSkill/GetFlavor/GetCellTag` 查询，共用 `IEffectDef` 接口进入结算。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | ID（主键） |
| name | string | 名称 |
| desc | string | 描述（`{0}` 会被 effectValue 回填） |
| effectType | [TagEffectType](#tageffecttype) | 效果类型 |
| effectValue | list,float | 效果数值（按效果类型解释） |
| effectParam | list,string | 效果参数 |
| termId | string | 关联术语ID（可空）→ `TbTerm.id` |

#### TbTerm — 专有名词
菜品详情右侧框单独解释的名词。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 术语ID（主键） |
| name | string | 术语名称 |
| desc | string | 术语解释 |

### 5.2 角色 / 胃 / 菜谱

#### TbCharacter — 角色
配置初始内容，并通过 `timelinePool`/`bossPool` 限制该角色可随机到的行动轴和 Boss。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 角色ID（主键） |
| name | string | 角色名称 |
| desc | string | 角色描述 |
| portrait | string | 角色立绘资源路径（美术） |
| initialRecipeId | string | 初始菜谱ID → `TbRecipe.id` |
| initialFragmentId | string | 初始胃碎片ID → `TbStomachFragment.id` |
| maxStomachWidth | int | 胃最大宽度 |
| maxStomachHeight | int | 胃最大高度 |
| timelinePool | string | 可用行动轴池，空=全部；逗号分隔 `TbTimeline.id` |
| bossPool | string | 可用Boss池，空=全部；逗号分隔 `TbBoss.id` |
| startItems | list,string | 初始携带道具ID列表 → `TbItem.id` |

#### TbStomachFragment — 胃部碎片
也用作初始胃形状来源。碎片**不旋转**（1x2 与 2x1 视为两个碎片）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 碎片ID（主键） |
| baseWeight | float | 随机基础权重 |
| price | int | 商店价格 |
| hiddenRange | [HiddenRange](#hiddenrange) | 出现隐藏分区间，单元格写 `min,max` |
| `*shapeRows` | list,string | 碎片形状，每行字符串，`'X'`=存在格（多行模式） |

#### TbFragmentCellTag — 碎片格强化标签
一行=碎片某格 (x,y) 挂一个标签。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 记录ID（主键） |
| fragmentId | string | 胃碎片ID → `TbStomachFragment.id` |
| x | int | 格子X坐标（0基） |
| y | int | 格子Y坐标（0基） |
| tagId | string | 挂载格子标签ID → `TbCellTag.id` |

#### TbRecipe — 菜谱
固定菜品 + 加权放回随机池，随机到累计初始分 ≥ `requiredInitScore` 为止。`fixedDishes` 用普通字符串保存，多个菜品以 `|` 分隔，避免与行末多行字段 `*pool` 冲突。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 菜谱ID（主键） |
| fixedDishes | string | 固定初始菜品ID列表，多个用 `|` 分隔 → `TbDishVariant.id` |
| requiredInitScore | int | 初始要求分（随机池累计阈值） |
| `*pool` | list,[RecipeEntry](#recipeentry) | 随机菜品池，单元格写 `dishId,weight,maxCount,initScore`（多行模式） |

| resultValue | float | 选项结果数值 |
| resultParam | string | 选项结果参数 |

### 5.5 行动轴 / 周

#### TbWeek — 周/关卡
进入新周时先读 Week 再按 `isBoss` 筛选 Timeline。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 周序号（=`GameRun.WeekIndex`，主键，按 id 决定总周数） |
| scoreProfileId | string | 本周基础目标分曲线 → `TbScoreProfile.id` |
| rewardPackageId | string | 本周默认奖励包，行动有 rewardPackageId 时优先用行动的 → `TbRewardPackage.id` |
| rewardHiddenScore | int | 本周默认奖励隐藏分；行动派生隐藏分 >0 时优先 |
| isBoss | bool | 是否 Boss 周（匹配 weekFilter=boss 的轴/组） |
| modifier | string | 周级修饰符（主要用于表现/扩展） |

#### TbScoreProfile — 目标分曲线
`Week.scoreProfileId` 与 `Boss.scoreProfileId` 引用它生成普通与 Boss 目标分。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 曲线ID（主键） |
| baseScore | int | 基础目标分 |
| difficultyMul | float | 普通难度倍率（本周基础分先乘它） |
| bossMul | float | Boss 目标分倍率（Boss 节点结算时额外应用） |
| endlessGrowthMul | float | 无尽模式超出配置周数后的指数增长倍率 |
| roundTo | int | 目标分向上取整粒度（如 10=取整到 10 倍数） |

#### TbRewardPackage — 奖励包
`Week.rewardPackageId`/`Action.rewardPackageId` 引用它，槽组继续指向 `reward.xlsx/reward_slot`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 包ID（主键） |
| goldMin | int | 基础金币奖励下限（实际结合隐藏分/行动曲线派生） |
| goldMax | int | 基础金币奖励上限 |
| mainSlotGroupId | string | 主奖励槽组ID → `TbRewardSlot.groupId` |
| extraSlotGroupId | string | 额外奖励槽组ID（extraChance 命中时抽取） |
| extraChance | float | 额外奖励出现概率（0..1） |
| fallbackGold | int | 候选无法生成/溢出时的兜底金币 |

#### TbTimeline — 行动轴库
按当前 Week 的 `isBoss` 与 `weekFilter` 筛选后按 `weight` 随机。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 行动轴模板ID（主键，运行态只存 id，读档重建节点） |
| weekFilter | string | 周筛选：空=任意，normal=非Boss周，boss=Boss周，或逗号分隔周号 |
| weight | float | 同筛选命中的轴之间按权重随机 |
| baseLengthDays | int | 行动轴基础长度（当前主循环按 7 天推进） |

#### TbTimelineNode — 行动轴节点
同 `timelineId` 多行组成一条轴；推进时触发 `prevDay < day <= newDay` 且未触发过的节点，按 `day` 升序结算。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 节点ID（主键，同节点每周只触发一次） |
| timelineId | string | 所属行动轴ID → `TbTimeline.id` |
| day | int | 整天位置 |
| nodeType | [TimelineNodeType](#timelinenodetype) | 节点类型（Boss/Interest/Shop/Event） |
| payloadValue | float | 数值参数（Interest=金币阈值 N，其它暂未用） |
| payloadParam | string | 字符串参数（Interest=每阈值金币数；Boss=Boss id 池筛选；Event=指定事件 id） |

### 5.6 奖励 / Boss / 数值曲线

#### TbRewardSlot — 奖励槽
同 `groupId` 内按 `weight` 选一个槽，再按槽规则生成候选。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 奖励槽ID（主键） |

| choiceCount | int | 候选数量 |
| weight | float | 槽权重 |
| poolId | string | 使用的奖励池ID → `TbRewardPool.id` |
| hiddenOffset | int | 隐藏分偏移 |
| fallbackGold | int | 兜底金币数量 |

#### TbRewardPool — 奖励池筛选
`qualityWeights` 写 `Common:70|Uncommon:25|Rare:5`；`specialTags` 用 `|` 分隔。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 奖励池ID（主键） |
| kind | [RewardPoolKind](#rewardpoolkind) | 奖励池类型 |
| specialTags | string | 特殊标签筛选，`|` 分隔 |
| qualityWeights | string | 品质权重，写 `Common:70|Uncommon:25|Rare:5` |
| allowFallback | bool | 是否允许兜底 |
| distanceFloor | int | 与当前进度的隐藏分下限距离 |

#### TbHiddenScoreCurve — 隐藏分曲线
按用途、周/序号分段生成基础与派生隐藏分。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 曲线ID（主键） |
| purpose | string | 用途：Base/TargetScore/Dish/PassiveItem/ActiveItem/Fragment |
| segmentPriority | int | 分段优先级，越大越优先 |
| minWeek / maxWeek | int | 适用周数范围，`<=0`=不限 |
| minRunStep / maxRunStep | int | 适用整局行动序号范围，`<=0`=不限 |
| baseValue | int | 基础值 |
| baseMultiplier | float | 基础倍率 |
| perWeek | float | 每周递增值 |
| perDay | float | 每推进一天递增值 |
| perStep | float | 每执行一次行动递增值 |
| normalBonus / hardBonus / bossBonus | int | 普通/困难/Boss 难度加成 |
| itemBonusMultiplier | float | 道具隐藏分派生倍率 |
| roundTo | int | 向上取整粒度 |
| minValue | int | 最小值 |

#### TbGoldRewardCurve — 金币奖励曲线
按进度和行动难度计算金币上下限。

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| minPerWeek / maxPerWeek | float | 下限/上限每周递增值 |
| minPerDay / maxPerDay | float | 下限/上限每行动轴天数递增值 |
| normalMinBonus / normalMaxBonus | int | 普通难度下限/上限加成 |
| hardMinBonus / hardMaxBonus | int | 困难难度下限/上限加成 |
| bossMinBonus / bossMaxBonus | int | Boss 难度下限/上限加成 |

#### TbBoss — Boss
Boss 节点按权重随机。`characterPool` 空=任意角色；`week=0` 任意周；`scoreProfileId` 空=用当前周曲线。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | Boss配置ID（主键） |
| name | string | Boss 显示名称 |
| characterPool | string | 角色池，空=任意；逗号分隔 `TbCharacter.id` |
| unlockCondition | string | 解锁条件，空=默认解锁 |
| weight | float | 同候选池内按权重随机 |
| week | int | 限定周序号，0=任意 Boss 周 |
| scoreProfileId | string | Boss 目标分曲线，空=用当前周曲线 → `TbScoreProfile.id` |
| modifier | string | Boss 特殊机制标识（如 limit_serve/small_board） |

## 7. Bean（复合单元格）字典

bean 把多个字段塞进一个单元格，用 `sep` 分隔。来源：`GameConfig/Datas/__beans__.xlsx`。

### RecipeEntry
菜谱池随机条目，单元格写 `dishId,weight,maxCount,initScore`（`sep=,`）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| weight | float | 权重 |
| maxCount | int | 最大数量（0=不限） |
| initScore | int | 本菜谱内初始分（用于累计 requiredInitScore） |

### LevelWeightParams
等级权重参数，单元格写 `maxLevel,nextLevelWeightMultiplier,baseWeight`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| maxLevel | int | 被动道具可升到的上限 |
| nextLevelWeightMultiplier | float | 已持有时再被抽中的权重系数 |
| baseWeight | float | 随机基础权重 |

### HiddenRange
出现隐藏分区间，单元格写 `min,max`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| min | int | 出现隐藏分下限 |
| max | int | 出现隐藏分上限 |
