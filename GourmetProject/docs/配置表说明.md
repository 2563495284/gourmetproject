# GourmetProject 配置表说明

> 面向 **策划 / 美术 / 程序** 的统一配置词典。
> 目标：任何人拿到这份文档，不用翻代码也能看懂「每张表是干什么的、每个字段填什么、值会流向哪里」。

- **配置源**：`GameConfig/Datas/*.xlsx`（schema 与数据都在 Excel 里，**不写 JSON 源数据**）。
- **生成产物（勿手改）**：代码 → `Assets/GameMain/Scripts/Config/Gen/`；运行时数据 → `Assets/StreamingAssets/Config/*.json`。
- **生成命令**：`bash GameConfig/gen.sh`（需要 .NET SDK 8.0+）。
- **运行时访问**：统一走 `GameApp.Config.Tables.TbXxx.Get(id)`。
- **记录数**：本文中各表的「记录数」为 2026-06-25 生成时的数据行数，仅供参考，会随表更新变化。

## 1. 给三个工种的快速指引

| 角色 | 你主要关心 | 怎么读这份文档 |
| --- | --- | --- |
| **策划** | 数值、概率、解锁、节奏 | 直接看每张表的字段表与「填写提示」，重点是 `weight / 曲线 / 区间 / preconditions`。 |
| **美术** | 资源路径字段 | 搜索 `icon / portrait / 图标 / 立绘`，这些字段填资源路径，命名规范见各表备注。 |
| **程序** | 数据流向、消费方 | 看每张表的「出处与引用」，里面列出读取该表的运行时服务。 |

改字段记住三件事：① 在数据 xlsx 改表头（`##var`/`##type`/`##comment`）；② 在 `__tables__.xlsx` 登记（仅新增表时）；③ 跑 `gen.sh`。详见 [`.cursor/rules/luban-config.mdc`](../.cursor/rules/luban-config.mdc)。

## 2. 配置体系总览

```
GameConfig/Datas/*.xlsx ──(luban.conf)──> bash GameConfig/gen.sh ──┬─> Config/Gen/*.cs   (Tables 访问层)
                                                                   └─> StreamingAssets/Config/*.json (运行时数据)
                                                                            │
                                                          ProcedurePreload 整局加载一次
                                                                            │
                                                          GameApp.Config.Tables.TbXxx
```

挂载关系来自 [`GameConfig/luban.conf`](../GameConfig/luban.conf)：

| schema 文件 | 类型 | 作用 |
| --- | --- | --- |
| `Defines/builtin.xml` | — | 框架自带（vec2/vec3 等），玩法不碰 |
| `Datas/__enums_*.xlsx` | enum | 枚举定义（按主题拆多个文件，如 tag/item/reward/action/unlock/dish） |
| `Datas/__beans__.xlsx` | bean | 复合单元格子结构（`RecipeEntry` 等） |
| `Datas/__tables__.xlsx` | table | **表登记**：一行=一张表 |

## 3. 阅读约定

### 3.1 数据表表头三行
每个数据 sheet 的首列单元格用 `##` 标记行类型，字段结构「直接读表头」：

| 标记行 | 含义 |
| --- | --- |
| `##var` | 字段名（程序里的属性名） |
| `##type` | 字段类型（**结构来源**） |
| `##comment` / `##` | 字段注释（会进生成代码的文档） |

### 3.2 类型写法

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `string` `int` `float` `bool` | 基础类型 | `42` / `3.5` / `true` |
| 枚举名 | 见 [第 6 节枚举字典](#6-枚举字典)，填**枚举名字符串** | `Passive` `Boss` |
| `list,string` | 字符串数组（多行模式，字段名前加 `*`） | 形状/标签列表 |
| `list,Bean` | 复合元素数组，每元素一个单元格，靠 bean 的 `sep` 切分 | `rice,150,0,5` |
| `Bean` | 单个复合值，一个单元格按 `sep` 切分 | `min,max` |

### 3.3 多元素 list（多行模式）
字段名前加 `*`（必须是最后一列）。每个元素占一行，**续行所有前导列留空**，靠主键列是否为空区分记录。例：`dish_base` 的 `*shapeRows`、`recipe` 的 `*pool`。

### 3.4 空值约定
- 字符串「空串」通常表示「无 / 任意 / 不限」，各表会在说明里点明（如 `weekFilter` 空=任意周、`characterPool` 空=任意角色）。
- 数值字段约定多见 `<=0 表示不限/使用默认`，以字段说明为准。

## 5. 逐表字段说明

> 字段表的「类型」与枚举/bean 链接到 [第 6 节](#6-枚举字典) / [第 7 节](#7-bean复合单元格字典)。
> 资源路径字段（`icon`/`portrait`）由美术维护。

### 5.1 菜品 / 技能 / 风味 / 格子标签

#### TbDishBase — 菜品本体
菜品不随技能/风味变化的物理属性。形状用 `*shapeRows` 多行字符串描述，`'X'` 表示占用格。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 菜品基础ID（主键） |
| name | string | 菜品名称 |
| deliciousness | int | 基础美味度（基础分） |
| icon | string | 图标资源路径（美术） |
| allowRotate | bool | 是否允许旋转摆放 |
| skills | list,string | 菜品技能ID列表 → `TbSkill.id`。**一菜一 skill**：实际每道菜只填一个 `sk_<菜id>`，该菜所有效果都是它的子技能 |
| category | string | 菜品分类（如 `cake`；空=无），供分类计数/浇灌类技能使用 |
| countAs | int | 「视为食物数」本体基础值，**恒为 1**；「视为N个食物」改由被动子技能（`ss_count_as_base`，作为该菜技能的一个子技能）承载，运行时按 `base 1 + 增量` 叠加 |
| `*shapeRows` | list,string | 菜品形状，每行一字符串，`'X'`=占用格（多行模式） |

> **填写提示**：sprite 尺寸按格子原生尺寸生成（1x1=512²、2x1=1024×512、2x2=1024²），纯食品不拟人化，见 [`food-asset-style.mdc`](../.cursor/rules/food-asset-style.mdc)。

#### TbDishVariant — 菜品变体（随机库条目）
引用本体 + 风味 + 隐藏分/权重/价格。菜品固有技能配置在 `TbDishBase.skills`；`flavorId` 空串=无风味（风味槽为空）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 变体ID（主键） |
| baseId | string | 引用的菜品本体ID → `TbDishBase.id` |
| flavorId | string | 风味ID（可空，单槽）→ `TbFlavor.id` |
| baseWeight | float | 随机基础权重 |
| price | int | 商店价格 |
| hiddenRange | [HiddenRange](#hiddenrange) | 出现隐藏分区间，单元格写 `min,max` |
| rotation | [DishRotation](#dishrotation) | 固定旋转朝向（整格四向）；`allowRotate=false` 时自动上菜只用该朝向 |

#### 技能两层模型（TbSkill → TbSubSkill）
技能拆成两层，把**技能编排**与**具体效果**分离，同一效果按参数复用、避免重复定义：

- **TbSubSkill（具体子技能）**：一行 = 一条完整效果，含全部 `SkillRuleDef` 字段（trigger/condType/condScope/condUnit/condMode/condCompare/condThreshold/condParam/actionType/actionScope/actionCount/actionValue/actionParam）+ `isPassive/signed/descTemplate`。**参数不同即视为不同子技能**；内容完全相同的子技能可被多个技能复用（如「倍率×5 作用自身」被多个技能共享）。
- **TbSkill（技能元信息）**：`id/termId/descOverride/subSkills`；`subSkills` 正向、有序引用子技能 id（`|` 分隔），执行顺序即列表下标。描述由所引用子技能的占位符模板**按序自动拼接**（`descOverride` 非空时覆盖）。技能展示标题按 `termId` 术语名（无则空）。

运行时适配层（`GameplayContentBuilder`）遍历 `subSkills`，把每个具体子技能合成为现有的 `SkillRuleDef`（`order`=下标）。**一菜一 skill**：`TbDishBase.skills` 每菜只引用一个技能，甜蜜传递作为其子技能；运行时甜蜜传递把「本 skill 内其他子技能」作为外来子技能传给目标（`DishInstance.TransferredSkills`），目标本次美食结算时随自身一并施加、生效一次、美食结束清除。除此之外结算逻辑零改动。数据脚本 `build_dessert_dishes.py` 以「多个 skill 片段」的作者友好写法编写，`build_merged_skills()` 按菜合并、再展平去重成具体子技能。设计语义见 [`docs/design/技能.md`](design/技能.md)。

#### TbSkill — 技能元信息
技能挂在菜品本体上，数量无上限。`termId` 非空时菜品详情额外展示该名词，并作为技能卡展示标题（无则不显示标题）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 技能ID（主键） |
| termId | string | 关联术语ID（可空）→ `TbTerm.id`；同时用作技能卡展示标题（术语名，空=无标题） |
| descOverride | string | 描述覆盖（**空=由子技能占位符模板按序自动拼接**；非空则直接使用该文本，用于多子技能读起来割裂或无子技能的技能） |
| subSkills | string | 有序引用的子技能ID列表（`|` 分隔）→ `TbSubSkill.id`，顺序即 `order` |

#### TbSubSkill — 具体子技能（完整效果 + 占位符描述）
一行 = 一条完整效果。前提求值出 `count`，行为按 `效果 × count` 施加到 `actionScope`。参数不同即不同子技能。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 子技能ID（主键，如 `ss_transfer_row_n1`、`ss_mult_v1p5`、`ss_count_as_base_v1`） |
| trigger | [SkillTrigger](#skilltrigger) | 触发时机（OnSettle/OnServe） |
| condType | [SkillConditionType](#skillconditiontype) | 前提类型（None=无前提，恒触发一次） |
| condScope | [SkillScope](#skillscope) | 前提作用域 |
| condUnit | [CountUnit](#countunit) | 计数单位（Instances 个 / Kinds 种） |
| condMode | [CountMode](#countmode) | 计数模式（Per/Reach/Gate） |
| condCompare | [CompareOp](#compareop) | 比较符（Reach/DishSize/RecipeCount 用） |
| condThreshold | int | 阈值 |
| condParam | string | 前提附加参数（如 `1x1`、`settled`、`self`、`tiers:3\|5\|8`） |
| actionType | [SkillActionType](#skillactiontype) | 行为类型 |
| actionScope | [SkillScope](#skillscope) | 行为作用域（目标） |
| actionCount | int | 随机目标数（0=全部） |
| actionValue | list,float | 行为数值 |
| actionParam | list,string | 行为参数（如 `mult`、`tiervals:1.5\|2.5\|5`、`cat:cake`、`multfloor:5`） |
| isPassive | bool | 被动标记（如「技能额外结算」「视为N食物」） |
| signed | bool | 描述数值是否补正负号（加减类 true / 倍率类 false，沿用 `TagDescFormatter` 语义） |
| descTemplate | string | 占位符描述模板，见下方占位符表 |

**描述占位符**（由 `SkillDescComposer` 用合成后的规则回填）：

| 占位符 | 含义 |
| --- | --- |
| `{0}`/`{1}`… | `actionValue[i]`（signed=true 补正负号，倍率类配合模板里的 `×`） |
| `{cscope}`/`{ascope}` | 前提/行为作用域词：自身/周围/同行/同列/全场 |
| `{atargets}` | 行为作用域「X食物」前缀：Self→空串，其余→周围食物/同行食物/… |
| `{unit}` | 计数单位：个 / 种；`{thr}` 阈值；`{count}` 目标数 |
| `{countas}` | 本体「视为N个食物」总数（=`actionValue`+1，因 `dish_base.countAs` 恒为 1，子技能存增量 N-1） |
| `{targets}` | 甜蜜传递目标短语（作用域 + 目标数，0=所有） |
| `{tiers}` | `condParam` 里 `tiers:` 解析为 `3/5/8`；`{tiervals}` `actionParam` 里 `tiervals:` 解析为 `1.5/2.5/5` |
| `{floor}` | `actionParam` 里 `multfloor:`/`floor:` 的值；`{cat}` 分类名（cake→蛋糕） |

技能总描述 = 各子技能按 `subSkills` 顺序用其 `descTemplate` 回填后，用「；」拼接。

#### TbFlavor / TbCellTag — 风味 / 格子标签
两张表仍使用简易效果字段：**风味**挂在菜品上，单槽后者替换前者；**格子标签**挂在胃碎片格上（`TbFragmentCellTag` 引用）。运行时经 `GameplayDatabase.GetFlavor/GetCellTag` 查询，共用 `IEffectDef` 接口进入结算。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | ID（主键） |
| name | string | 名称 |
| desc | string | 描述（`{0}` 会被 effectValue 回填） |
| effectType | [TagEffectType](#tageffecttype) | 效果类型 |
| effectValue | list,float | 效果数值（按效果类型解释） |
| effectParam | list,string | 效果参数 |
| termId | string | 关联术语ID（可空）→ `TbTerm.id` |

#### TbTerm — 专有名词
菜品详情右侧框单独解释的名词。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 术语ID（主键） |
| name | string | 术语名称 |
| desc | string | 术语解释 |

## 7. Bean（复合单元格）字典

bean 把多个字段塞进一个单元格，用 `sep` 分隔。来源：`GameConfig/Datas/__beans__.xlsx`。

### RecipeEntry
菜谱池随机条目，单元格写 `dishId,weight,maxCount,initScore`（`sep=,`）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dishId | string | 菜品ID → `TbDishVariant.id` |
| weight | float | 权重 |
| maxCount | int | 最大数量（0=不限） |
| initScore | int | 本菜谱内初始分（用于累计 requiredInitScore） |

### LevelWeightParams
等级权重参数，单元格写 `maxLevel,nextLevelWeightMultiplier,baseWeight`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| maxLevel | int | 被动道具可升到的上限 |
| nextLevelWeightMultiplier | float | 已持有时再被抽中的权重系数 |
| baseWeight | float | 随机基础权重 |

### HiddenRange
出现隐藏分区间，单元格写 `min,max`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| min | int | 出现隐藏分下限 |
| max | int | 出现隐藏分上限 |
